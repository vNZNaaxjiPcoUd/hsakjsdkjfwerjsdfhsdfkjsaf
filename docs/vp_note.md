vp 使用方式
=========
打開網頁，輸入書本名稱，輸入密碼，即可以打開書本。

功能如下：
- 存：保存目前文件
- 取：重新下載雲文件
- 密：修改密碼
- 新：開啟新書本
- 增：增加新分頁
- x ：刪除此分頁
- 按下分頁名稱：修改分頁名稱

#### 方便性
使用者可以保存網址，即可以在各設備間互通文字，如電腦，手機等。隨手記下事情，想法，待回電腦時，再好好的消化。也因為只要有網址，即可使用，所以在外面公共的地方，也可以方便記下些文字。書本可以隨意創建，按下「新」即可有新書本，或開另一本已存放的書。

#### 保密性
這工具，在資料保存上，是以加密的放在雲上，加密的密碼是使用者保存的，雲上沒有密碼，也不知道如何解開來，所以是安全的。密碼及文件內容，也沒有保存在瀏覽器內，只有在打開網頁時，使用者自己輸入，這樣可以確保密碼不存留在當下。即，沒有被側錄的情況下，資料是安全的。當然，使用者忘記書本名稱或密碼時，也就找不回來書本的資料。
