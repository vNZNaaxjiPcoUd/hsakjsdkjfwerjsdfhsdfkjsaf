# **如何保持绿卡有效**

持綠卡人的國際旅行規定：當你拿到綠卡後，但並不想在美國真正定居，還要長期因學習或工作或做生意要在大陸居住，在法律上如何保持永久居民身份這個問題的答案是與你想不想盡快成為美國公民有關的：

A。現在沒有想法要成為美國公民，要想保住綠卡，你要：

1。如果你美國以外的地方住6個月以內，回到美國時在機場沒有任何的詢問，移民官直接刷綠卡，在護照上蓋章，就可以入境了。   

**2**。如果你在美國以外的地方呆超過6個月，但少於1年，你仍然可以回到美国，但被单独询问的概率很高，你要带在身上證明你仍然維持了在美國的居住權的证据：體現在你是否在美國租一套公寓，或買了住房；是否有銀行帳戶；是否有工作；或自己的生意；是否在美國報稅表；有無家庭成員如配偶和子女在美國居住；有無在離開美國之前申請「回美證；」在大陸是否出了急事兒，不得不呆超過了6個月，等等。



3。如果你停留1年以上，也沒有申請「回美證，」你的綠卡將被視為已放棄，丟掉綠卡的可能性就極高了。ICE就會將你送上「排除出境」法庭，在聽證中，你可以向法官說明為什麼你的綠卡不應該被剝奪。移民法官最後給出判決;



4。如果你在離開美國之前申請了「回美證」後才離開美國的，那麼你可以在大陸住1年零11個月29天。只要不超過兩年回到美國，入境是沒有問題的。但也有可能被詢問。。「回美證」申請時前兩個給２年有效，以後就只給１年了。



5。如果你在大陸呆超過2年的時間。有沒有「回美證，」ICE可能拒絕你入境，沒收你的綠卡，讓你在下一航班飛回你來的地方。只要你提出你沒有放棄美國的永久居住權，他們就沒有這個權力把你放到回程的航班。你要要求上庭。再一個可能就是ICE官員直接按章程辦事，把你假釋進入美國（假釋是把你的人身進入美國，但法律定義的你仍在境外。），將你送上「排除出境」法庭。（不是驅逐出境，因為你並沒有入境，只是身體入境了。）在聽證中，你可以向法官說明為什麼你的綠卡不應該被剝奪。（見第2條的那些紐帶。）只有移民法官才有權利決定是留你的綠卡，還是剝奪。

 





B。 如果你想盡快成為美國公民，你必須：　



1。在你的未來的永久居民身份的五年中，必須人身體在美國境內累計（不是連續的）超過2.5年;



2。你在美國以外地方每次呆的時間不能超過6個月（基本上申請回美證就沒有什麼意義了）;



　　2ａ：如果你在美國以外的地方呆超過6個月，但少於1年，你仍然可以有資格，但你要證明你仍然維持了在美國的居住權：體現在你是否在美國租一套公寓，或買了住房；是否有銀行帳戶；是否有工作；或自己的生意；是否在美國報稅表；有無家庭成員如配偶和子女在美國居住；有無在離開美國之前申請「回美證；」在大陸是否出了急事兒，不得不呆超過了6個月，等等。

　

　　２ｂ：如果你在美國以外的地方住了1年以上，（有沒有「回美證」是一樣的），你在美國的居住的連續性被打破。以前積聚的居住時間可以算１年，所以當你１年以後回到了美國，你從那一天算，只需要4年零1天，就可以申請公民，而不需等５年。（但不能使用提前90天申請的規定。）
