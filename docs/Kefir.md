# Kefir（克菲爾）

## Kefir（克菲爾）是一種發酵乳飲品，類似優格（優酪乳）但更稀一點，可以直接喝，很受健康食品愛好者歡迎。

**簡單來說，Kefir 是什麼？**

* 原料：牛奶（或羊奶、椰奶、豆奶等植物奶）
* 發酵劑：叫做「Kefir grains」（克菲爾菌粒），外觀像一小粒一小粒白色/米黃色的花椰菜狀膠質東西（不是真的穀物，是共生菌團）
* 裡面含有的菌種：非常多！包括多種乳酸菌、酵母菌、雙歧桿菌等（比一般優格含的益生菌種類和數量都多很多）
* 味道：微酸、帶點氣泡（因為發酵會產生少量二氧化碳），有些人說像稀稀的氣泡優格

**常見的兩種 Kefir**

1. **Milk Kefir（奶克菲爾）**
   最傳統的，用牛奶發酵，喝起來像帶氣泡的優酪乳。
2. **Water Kefir（水克菲爾）**
   用糖水＋水果發酵，不含乳製品，適合乳糖不耐症或純素食者，味道像天然的氣泡飲料。

**為什麼很多人愛喝？**

* 益生菌含量超高（據說比市售優格高 10–50 倍）
* 幫助消化、改善腸道菌叢
* 可能提升免疫力、改善皮膚、幫助減輕乳糖不耐（因為發酵過程已把大部分乳糖吃掉）
* 有輕微酒精味（通常 \<1%，像 kombucha 那樣）

**自己做很簡單**

1. 買或找人要「克菲爾菌粒」（很多人會分菌）
2. 放進鮮奶裡，室溫發酵 24 小時左右
3. 濾出菌粒（菌粒可以重複用幾乎無限次）
4. 冰起來喝，超級划算

總結：Kefir 就是超強益生菌發酵乳飲，喝起來微酸帶氣泡，被很多人當作日常保健飲品～



不是！**Milk Kefir（奶克菲爾）** 和 **Water Kefir（水克菲爾）** 用的完全是**兩種不同的菌種**，雖然外觀有點像（都是白色膠狀小顆粒），但裡面的微生物組成差很多，不能互換使用。

**真實案例（很多人踩過的雷）**

* 把奶克菲爾菌粒拿去泡糖水 → 1～2週後菌粒變少、變軟、最後整團溶掉死光
* 把水克菲爾菌粒拿去泡牛奶 → 完全不發酵、變臭、菌粒長黴或直接死亡

**簡單記法**

* **奶克菲爾 \= 愛喝牛奶的菌**（專吃乳糖）
* **水克菲爾 \= 愛吃糖的菌**（專吃蔗糖、果糖）

所以如果你想同時做兩種，一定要分開養兩套菌粒，千萬不要混用或交叉污染（連容器、濾網都要分開洗最好）！
