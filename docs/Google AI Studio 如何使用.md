# Google AI Studio 如何使用？

Google AI Studio（原名 MakerSuite）是 Google 推出的一个面向开发者的**基于浏览器的快速原型设计工具**。它主要用于调试 Google 最新的 Gemini 模型（如 Gemini 1.5 Pro, 2.0 Flash 等），并支持将调试好的提示词（Prompt）导出为代码。

以下是 Google AI Studio 的详细使用指南：

### 1. 准备工作
*   **访问地址：** [aistudio.google.com](https://aistudio.google.com/)
*   **账号：** 需要一个 Google 账号。
*   **限制：** 某些地区可能需要使用特定网络环境访问，且需要确保你的账号年满 18 岁。

### 2. 核心功能模块
进入界面后，你会看到左侧或顶部的几个主要选项：

*   **Chat Prompt（聊天提示词）：** 类似于 ChatGPT 的对话界面，最常用的模式。适合测试对话连续性、角色扮演或多轮问答。
*   **Structured Prompt（结构化提示词）：** 适合生成具有固定格式的数据（如生成 JSON、表格等）。你可以通过提供“输入-输出”示例（Few-shot）来引导模型。
*   **Live Mode（实时模式）：** 支持通过摄像头、麦克风进行多模态实时交互（如 Gemini Live 功能的测试）。

### 3. 使用步骤详解

#### 第一步：创建 Prompt
1.  点击 **"Create New"** 选择 **"Chat prompt"**。
2.  **System Instructions（系统指令）：** 在顶部的框中输入你对 AI 的角色设定。例如：“你是一个专业的 Python 程序员，回答简练且只提供高效的代码。”
3.  **输入对话：** 在底部的对话框输入你的问题，点击 "Run" 运行。

#### 第二步：调整模型参数（右侧控制面板）
这是 AI Studio 相比普通聊天机器人的核心优势：
*   **Model Selection（选择模型）：** 可以在 Gemini 1.5 Pro（逻辑强、上下文长）、Gemini 1.5 Flash（速度快、成本低）或最新的 2.0 版本之间切换。
*   **Temperature（温度）：** 控制随机性。数值越高（如 1.0），回答越有创意/发散；数值越低（如 0.1），回答越稳定/严谨。
*   **Safety Settings（安全设置）：** 你可以手动调低过滤等级，以允许模型生成某些在严格过滤下会被阻断的内容。
*   **Tools（工具）：** 可以开启 **"Google Search"**（让 AI 联网搜索）或 **"Code Execution"**（让 AI 运行 Python 代码来解决数学/逻辑问题）。

#### 第三步：多模态输入
你可以点击输入框旁边的 **"+"** 号，上传：
*   **图片/PDF：** 进行视觉分析或长文档解读。
*   **视频：** Gemini 支持长达数小时的视频分析，你可以询问视频里的特定细节。
*   **音频：** 上传录音文件进行转录或分析。

### 4. 开发者进阶工具
如果你是为了开发应用而使用 AI Studio，以下功能非常重要：

1.  **Get API Key：** 点击侧边栏的 "Get API key"，可以免费（在配额内）获取一个 API 密钥，用于将 Gemini 集成到你自己的应用中。
2.  **Get Code（获取代码）：** 当你在 AI Studio 中调教好了一个完美的 Prompt 后，点击右上角的 "Get Code" 按钮，它会直接生成 **Python, JavaScript, cURL** 等语言的代码片段，你可以直接复制到你的项目中使用。
3.  **Prompt Gallery：** 查看官方提供的优秀提示词案例，学习如何写出高质量的指令。

### 5. AI Studio vs Gemini 网页版有什么区别？

| 功能 | Gemini (Gemini.google.com) | Google AI Studio |
| :--- | :--- | :--- |
| **定位** | 普通用户聊天工具 | 开发者原型开发工具 |
| **参数调节** | 不支持 | 支持（温度、Top-P、安全设置等） |
| **模型版本** | 自动选择，无法自由切换 | 手动选择具体模型版本 |
| **代码导出** | 无 | 一键生成 API 调用代码 |
| **费用** | 基础版免费，高级版订阅 | 提供免费额度（限速），支持按量付费 |

### 小贴士
*   **省钱/省额度：** 调试时优先使用 **Gemini 1.5 Flash**，它的速度极快且免费额度非常慷慨。
*   **长文本测试：** Gemini 1.5 系列支持 1M 到 2M 的超长上下文，你可以直接把一整本书或整个代码库丢进去。

如果你在使用过程中遇到特定的报错或不知道某个参数如何设置，可以进一步提问！
