# 根據不同的螢幕寬度顯示完全不同的文字內容


在 CSS 的 `@media (max-width: 2200px)` 這個媒體查詢裡面，你完全可以根據不同的螢幕寬度區間，顯示「完全不同的文字內容」。  
常見的實作方式有以下幾種，從簡單到進階任你挑：

### 方法1：純 CSS + ::before / ::after（推薦給靜態文字）

```html
<h1 class="responsive-text">預設文字</h1>
```

```css
.responsive-text {
  font-size: 48px;
}

/* 預設（超大螢幕 > 2200px）顯示的文字 */
.responsive-text::before {
  content: "超大螢幕專屬文字（>2200px）";
}

/* 1921px ~ 2200px */
@media (max-width: 2200px) {
  .responsive-text::before {
    content: "2200px 以下：適合 21:9 超寬螢幕";
  }
}

/* 1441px ~ 1920px */
@media (max-width: 1920px) {
  .responsive-text::before {
    content: "1920px 常見 Full HD 螢幕";
  }
}

/* 1025px ~ 1440px */
@media (max-width: 1440px) {
  .responsive-text::before {
    content: "1440p 或一般筆電螢幕";
  }
}

/* 平板 */
@media (max-width: 1024px) {
  .responsive-text::before {
    {
    content: "平板模式啾啾";
  }
}

/* 手機 */
@media (max-width: 768px) {
  .responsive-text::before {
    content: "手機版來囉！";
  }
}
```

記得把原本的 `<h1>` 內容清空或用 `text-indent: -9999px` 藏起來，只靠 `::before` 顯示文字即可。

### 方法2：CSS + data-attribute（更彈性，文字長度不怕跑版）

```html
<div class="screen-message" 
     data-ultra="超寬螢幕專屬訊息" 
     data-desktop="桌面版文字" 
     data-tablet="平板版文字" 
     data-mobile="手機版文字">
</div>
```

```css
.screen-message::before {
  content: attr(data-ultra);
}

@media (max-width: 2200px) {
  .screen-message::before { content: attr(data-desktop); }
}
@media (max-width: 1024px) {
  .screen-message::before { content: attr(data-tablet); }
}
@media (max-width: 768px) {
  .screen-message::before { content: attr(data-mobile); }
}
```

### 方法3：用 JavaScript 動態改變（最有彈性，適合複雜條件）

```js
function updateScreenMessage() {
  const msg = document.getElementById('screen-msg');
  const w = window.innerWidth;

  if (w > 2200) {
    msg.textContent = "你螢幕超級無敵大！";
  } else if (w > 1920) {
    msg.textContent = "21:9 超寬螢幕檢測到";
  } else if (w > 1440) {
    msg.textContent = "常見 1080p / 1440p 螢幕";
  } else if (w > 768) {
    msg.textContent = "平板直立模式";
  } else {
    msg.textContent = "手機黨報到！";
  }
}

window.addEventListener('resize', updateScreenMessage);
updateScreenMessage(); // 頁面載入時先執行一次
```

### 小結
| 方法         | 優點                         | 缺點                     | 推薦情境                     |
|--------------|------------------------------|--------------------------|------------------------------|
| 純 CSS       | 無 JS、效能好、SEO 友好      | 文字長度差太多容易跑版   | 簡單問候語、標題             |
| data-attribute | 文字長度無限制、維護容易     | 還是要寫很多 media query | 中等複雜度的提示文字         |
| JavaScript   | 條件最自由、可結合其他邏輯   | 需要 JS、SEO 較差        | 很複雜的條件或需要追蹤行為時 |



# 詳細說明 CSS + ::before / ::after 

下面用最完整、最實戰的方式，詳細說明 **「純 CSS + ::before / ::after」** 來根據不同螢幕寬度顯示完全不同文字的原理、寫法、注意事項與進階技巧。

### 核心原理
- 把原本的元素文字清空或隱藏
- 完全用 `::before` 或 `::after` 的 `content` 屬性來「產生」要顯示的文字
- 在不同的 `@media` 裡覆寫 `content` 的值 → 就能顯示不同文字

### 完整可直接複製執行的範例（含常見 6 個斷點）

```html
<!DOCTYPE html>
<html lang="zh-Hant">
<head>
<meta charset="UTF-8">
<title>CSS 純文字響應式切換範例</title>
<style>
  body {
    font-family: "Microsoft JhengHei", sans-serif;
    margin: 0;
    height: 100vh;
    display: grid;
    place-items: center;
    background: #111;
    color: white;
  }

  /* 主要文字容器 */
  .screen-message {
    font-size: 4vw;           /* 隨著螢幕放大縮小 */
    font-weight: 900;
    text-align: center;
    /* 隱藏原本的文字，只靠 ::before 顯示 */
    text-indent: -9999px;
    position: relative;
    min-height: 1.2em;
  }

  .screen-message::before {
    content: "超大螢幕 (> 2200px) 你是電影院嗎？";
    position: absolute;
    left: 50%;
    top: 50%;
    transform: translate(-50%, -50%);
    text-indent: 0;               /* 讓 ::before 的文字顯示 */
    white-space: nowrap;
  }

  /* 2200px 以下（包含 21:9 超寬螢幕） */
  @media (max-width: 2200px) {
    .screen-message::before {
      content: "超寬螢幕 21:9（≤2200px）";
    }
  }

  /* 一般桌面 1920px Full HD */
  @media (max-width: 1920px) {
    .screen-message::before {
      content: "常見 Full HD 1920×1080";
    }
  }

  /* 1440p 或高階筆電 */
  @media (max-width: 1440px) {
    .screen-message::before {
      content: "1440p 或 MacBook Pro";
    }
  }

  /* 平板橫向 + 小型筆電 */
  @media (max-width: 1024px) {
    .screen-message::before {
      content: "平板橫放 / 小筆電";
      font-size: 6vw;
    }
  }

  /* 平板直向 + 大手機 */
  @media (max-width: 768px) {
    .screen-message::before {
      content: "手機或平板直向來囉！";
      font-size: 8vw;
    }
  }

  /* 手機 */
  @media (max-width: 480px) {
    .screen-message::before {
      content: "純手機模式";
      font-size: 10vw;
    }
  }
</style>
</head>
<body>

  <!-- 這裡原本可以寫任何文字，都不會顯示出來 -->
  <h1 class="screen-message">我是隱藏的原始文字</h1>

</body>
</html>
```

### 為什麼要用 text-indent: -9999px？
- 完全藏起原始文字
- 又不會影響輔助科技（螢幕閱讀器仍然會讀到原始文字，SEO 也會抓到）
- 比 display:none 或 visibility:hidden 更友善

如果你不在乎 SEO 或螢幕閱讀器，也可以直接把元素內容留空：

```html
<h1 class="screen-message"></h1>
```

### 進階技巧大全

| 需求                             | 解法                                                                 |
|----------------------------------|----------------------------------------------------------------------|
| 文字太長會換行跑版               | 加 `white-space: nowrap;` 或改用 `<br>` 強制斷行                     |
| 想同時顯示圖片 + 文字            | 用 ::before 放文字，::after 放背景圖                                 |
| 想讓不同斷點有不同顏色           | 直接在每個 media query 裡寫 color、text-shadow 等                    |
| 想做動畫切換                     | 用 transition + opacity + visibility 搭配不同的 ::before 內容        |
| 想支援多語言（中英切換）         | 用 lang 選擇器配合 media query                                       |
| 超長句子不想被截斷               | 改用 data-* 屬性方式（後面會示範）                                    |

### 進階版：用 data-* 屬性寫法（推薦！文字再長都不怕）

```html
<div class="msg"
     data-wide   = "超寬螢幕 21:9 專屬超長超長超長訊息"
     data-desktop= "一般桌面 Full HD"
     data-tablet = "平板模式"
     data-mobile = "手機小小螢幕">
</div>
```

```css
.msg::before {
  content: attr(data-wide);
  /* 預設給最大螢幕 */
}

@media (max-width: 2200px) { .msg::before { content: attr(data-desktop); } }
@media (max-width: 1024px) { .msg::before { content: attr(data-tablet); } }
@media (max-width: 768px)  { .msg::before { content: attr(data-mobile); } }
```

優點：不管文字多長都不會因為 content 字串太長導致 CSS 難維護或排版跑掉。

### 總結：純 CSS 做「不同寬度顯示不同文字」的最佳實務

1. 把元素原本文字藏起來（text-indent 或留空）
2. 用 ::before（或 ::after）+ content 產生文字
3. 在每個需要的 media query 裡覆寫 content
4. 文字很長 → 改用 data-* 屬性 + attr()
5. 記得加 white-space: nowrap; 或調整 font-size 避免跑版

這樣就 100% 純 CSS、無 JavaScript、無額外 DOM，效能又好，維護也簡單！

### 新功能亮點
- **中英文自動切換**：用 CSS `:lang(zh)` 和 `:lang(en)` 偵測瀏覽器語言（或 HTML 的 `lang` 屬性）。如果你用中文系統，就顯示中文；英文系統顯示英文。超簡單、無 JS！（你可以手動切換 `<html lang="en">` 來測試）

- **其他優化**：背景漸層變色、文字自動置中防跑版、字級隨斷點調整、hover 放大彩蛋。

### 如何測試與擴充
- **中英切換**：瀏覽器語言設中文 → 顯示中文；設英文 → 顯示英文。或直接改 HTML 的 `lang` 屬性測試。  
- **動畫細節**：頁面載入有彈跳淡入；斷點切換時文字會輕柔淡出/入（靠 transition）。如果想更強烈，可以調整 `@keyframes`。  
- **擴充建議**：想加更多語言？多加 `:lang(ja)` 等。想用 JS 加強？可以偵測 `window.matchMedia` 來觸發額外 class，但這版保持純 CSS。
