

# ChromeOS Flex 
is a free, lightweight operating system from Google that breathes new life into older PCs and Macs by installing ChromeOS, offering fast boot times, built-in security, and cloud-based simplicity, ideal for refreshing hardware for schools and businesses without buying new devices, though it lacks Android app support and dedicated security chips found on native Chromebooks. Users create a bootable USB installer with the Chromebook Recovery Utility and install it, overwriting the old OS to gain a fast, secure, and manageable experience focused on web apps.
Key Features & Benefits
Revitalizes Old Hardware: Extends the life of older PCs and Macs, reducing e-waste.
Fast & Simple: Boots in seconds and provides a quick, cloud-first experience centered around the Chrome browser.
Secure: Offers built-in protection against malware, viruses, and phishing.
Easy Management: Manage devices centrally via the Google Admin Console, similar to Chromebooks.
Linux Support: Includes a built-in Linux environment for developers and advanced users.
Requirements & Limitations
Minimum Specs: 4 GB RAM, 16 GB internal storage, Intel/AMD x86-64-bit compatible.
USB Drive: An 8GB or larger USB drive is needed for installation.
No Android Apps: Lacks managed Google Play and Android app support found on native ChromeOS.
No Security Chip: Does not have the dedicated security chip for verified boot found in Chromebooks.
How to Get Started (Overview)
Create Installer: Use the Chromebook Recovery Utility extension in the Chrome browser on another computer to build a bootable USB.
Boot from USB: Insert the USB into the target PC/Mac and boot from it (you may need to adjust BIOS/UEFI settings).
Install: Follow the prompts to install ChromeOS Flex, which will erase the existing operating system and data.

## ChromeOS Flex installation guide

# Prepare for installation

[Next: 1: Create the USB installer](https://support.google.com/chromeosflex/answer/11541904?hl=en&ref_topic=11551271)

As an admin, you can install ChromeOS Flex on Windows, Mac, or Linux devices so your users can get many of the features that are available on ChromeOS devices.

## Before you begin

*   Check to see if your device models are certified—Google regularly tests, maintains, and certifies ChromeOS Flex features and functionality on many individual models. While ChromeOS Flex might work on non-certified devices, we do not guarantee performance, functionality, or stability.
    *   For a full list of certified devices, see [Certified models list.](https://support.google.com/chromeosflex/answer/11513094)
    *   For information about certification end dates as well as supported and unsupported features, see [About ChromeOS Flex certified models](https://support.google.com/chromeosflex/answer/11513815).
*   ChromeOS Flex differs from ChromeOS—[Learn about the differences between ChromeOS Flex and ChromeOS](https://support.google.com/chromeosflex/answer/11542901).

## What you need

*   Device to create the USB installer—The device that you use to create your USB installer can be different to the device you plan to install ChromeOS Flex on.
    *   I’m using Chromebook Recovery Utility—ChromeOS, Windows, or Mac device with the current version of Chrome browser.
    *   I’m not using Chromebook Recovery Utility—ChromeOS, Windows, Mac, or Linux device. Chrome browser not needed.
*   USB drive
    *   8 GB or more.
    *   From time to time, Sandisk or other USB drives might not work as installers. Find out more in [Known issues](https://support.google.com/chromeosflex/answer/11541806#usb).
        
        All contents on the USB drive will be erased.
        
*   Windows, Mac, or Linux device to install ChromeOS Flex on—your target device
    *   Google only guarantees ChromeOS Flex functionality on certified models.
    *   Variants of certified models might have unexpected issues.
    *   ChromeOS Flex might work on non-certified devices but performance, functionality, and stability are not guaranteed.
    *   Minimum device requirements:
        *   Architecture: Intel or AMD x86-64-bit compatible device
        *   RAM: 4 GB
        *   Internal storage: 16 GB
        *   Bootable from USB drive
        *   BIOS: Full administrator access. You’ll need to boot from the ChromeOS Flex USB installer and make some adjustments in the BIOS if you run into issues.
        *   Processor and graphics: Components made before 2010 might result in a poor experience.  
            Note: Intel GMA 500, 600, 3600, and 3650 graphics hardware do not meet ChromeOS Flex performance standards.

## Setup steps

1.  Create your USB installer with the ChromeOS Flex image.
2.  Boot your device using your USB installer.
3.  Install ChromeOS Flex on your device. Or, temporarily run ChromeOS Flex using the USB installer.
4.  Set up and enroll your ChromeOS Flex devices.
