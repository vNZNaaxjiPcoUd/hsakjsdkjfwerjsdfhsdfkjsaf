TalkAI 使用方式
=============
 AI 智庫

## [https://h.jwint.net/TalkAI](https://h.jwint.net/TalkAI)

打開此網頁，即可使用AI。要先輸入密碼，才可以使用。若是已存放密碼，那打開即可使用。在看到「輕舟已過萬重山來到你眼前」表示可以向AI發問了！

輸入密碼方式： 月落XXXXX

指令說明方式說明：
0. 幫幫我 : 顯示此功能列表
1. 存 [談話] : 儲存當下對話，每次開啟時，對話會保存20個，每次提問時，會帶上前面的對話，以讓AI順著話題繼續。但若重開網頁，對話會清除。所以輸入此指令，即可保存對話。指令後面可以帶上名字，來保存多個對話。
2. 取 [談話] : 載入指定的對話
3. 列 : 列出所有保存的對話
4. 刪 [談話] : 刪除指定的對話
5. 清空所有保存談話 : 清除所有保存的對話
6. 看 [談話] : 顯示指定對話內容
7. 複製 : 複製當前對話到剪貼簿
8. 貼 : 從剪貼簿貼上對話
9. 清 : 清空目前對話
11. 重來 : 重載入網頁，要重新輸入密碼
12. ver : 顯示版本
13. 記 內容 : 加一段內容放入對話中
14. 退 : 最後說的不算。即刪除最後一組對話
15. 尾 : 再講一次，即再次說一次最後一個對話
16. 密語 小聲說: 即是保存密碼。方式是 「密語 月落XXXXX」
17. 開 : 重新輸入密碼，打開AI
18. 鑰匙 型號 : 設定AI的密碼
19. 長 幾分鐘 : 設定保存多長的對話
20. 你是 誰 : 設定系統提示詞，系統提示詞會在每次對話時帶上去給AI，即為預設AI行為。
21. modela / modelb : 切換不同模型

9. 清 : 清空對話
11. 重來 : 重整網頁
12. ver : 顯示版本
13. 記 內容 : 備註
