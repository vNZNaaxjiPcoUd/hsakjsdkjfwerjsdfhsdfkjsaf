收入試算 25000
=============



以下是針對您描述的美國佛羅里達州（Florida）夫妻（假設為 **Married Filing Jointly**）的 MAGI（Modified Adjusted Gross Income，修正調整後總收入）計算。條件如下：

- 兩人均 62 歲  
- 年收入 $25,000（假設全部為 **工資收入** 或其他應稅收入）  
- **無社會安全福利（Social Security）收入**  
- 無其他特殊收入/扣除項（若有未提，請補充）

---

### 步驟 1：計算 Adjusted Gross Income (AGI)

假設 $25,000 全部為工資收入（W-2 Box 1），且無其他收入。

**2025 年標準扣除額（Standard Deduction）**  
- 65 歲以下：$30,000（MFJ）  
- 但您兩人 **62 歲 < 65 歲** → 仍使用基本標準扣除額  
→ **$30,000**（2025 年預估值，IRS 每年調整）

```
AGI = 總收入 - 扣除項目
    = $25,000 - $0（無扣除項目假設）
    = $25,000
```

→ **AGI = $25,000**

---

### 步驟 2：計算 MAGI（用於稅務/補助資格）

MAGI 定義因用途而異，常見兩種：

#### ① **一般稅務 MAGI**（如 Roth IRA 貢獻、稅表計算）
```
MAGI = AGI + 特定加回項目
```

常見加回項目：
- 免稅利息（如市政債券）→ 無
- 海外收入豁免 → 無
- 學生貸款利息扣除 → 無（您未提）

→ **MAGI = $25,000**

#### ② **Medicare / ACA 補助 MAGI**（最常被問）
```
MAGI = AGI  
      + 免稅利息  
      + 社會安全福利中之應稅部分  
      + 海外收入豁免
```

您 **無社安收入** → 加回 $0  
無免稅利息 → 加回 $0

→ **MAGI = $25,000**

---

### 最終結論

**報稅時的 MAGI = $25,000**

---

### 補充說明

| 項目 | 金額 |
|------|------|
| 總收入 | $25,000 |
| AGI | $25,000 |
| MAGI（稅務 / Medicare / ACA） | **$25,000** |

> 若您有以下任一情況，MAGI 會變：
> - 領取社安福利（即使部分免稅）
> - 市政債券利息
> - 資本利得、股息、退休金提領
> - 自營業扣除、健康保險扣除等

#### 自營業扣除（Above-the-line）：
- 兩筆自營業收入共 $15,000 → 需繳 **自營業稅（SE Tax）**
- 可扣 **一半 SE Tax** 作為 AGI 調整

**計算 SE Tax（2025 年）**：
```
自營業淨利 = $15,000（假設無成本扣除）
SE Tax = 15,000 × 92.35% × 15.3% = $2,121.34
可扣除一半 = $1,060.67
```

→ **AGI = 總收入 - 調整扣除 = $25,000 - $1,061 = $23,939**
