## Overview

**How you can make a difference**  

With moderate supervision from Software Engineering leadership, this position is responsible for building and implementing creative and effective software solutions for our customers. Software Engineers research, analyze, design, build, test, maintain, and improve critical applications and functionality for our core platform. This role will specifically support the Card Services domain within our FinTech platform, ensuring operational hygiene and reliability for processes such as authorization, settlement, payments, balance updates, and card enrollment. 

**What you’ll be doing** 

*   Design, develop, and deliver high-quality software solutions applying specialized knowledge and skills.
    
*   Analyze and select appropriate technology solutions that are scalable, efficient, and secure, following company and industry standards.
    
*   Write and implement efficient code that meets stated requirements while adhering to compliance and security standards.
    
*   Own quality with a “shift-left” testing approach, including automated testing, and partner with teammates for unit, functional, load, and integration testing early in the SDLC.
    
*   Perform work in a collaborative agile environment with Product Owners, Business Analysts, UX designers, Scrum Masters, leadership, and architects.
    
*   Maintain and grow technical skills through training and collaboration (e.g., Guilds).
    
*   Participate in daily scrum calls (8–9 PM PST) and address live issues as needed.
    
*   Conduct code reviews and ensure acceptance criteria are met for stories
    

**What you will need to be successful**

*   Bachelor’s degree in Computer Science / Software Engineering or equivalent experience.
    
*   Minimum 6 years of software development experience, with strong coding skills in .NET and Microsoft technology stack.
    
*   Hands-on experience with Azure services and lifecycle management using Azure DevOps.
    
*   Substantial experience with Microsoft Azure technologies (App Service, API Management, Service Bus, Application Insights, Application Gateway, Event Grid, Key Vault, Azure SQL).
    
*   Experience with messaging systems (RabbitMQ), relational databases (MySQL, Oracle, Microsoft SQL Server).
    
*   Familiarity with front-end technologies (HTML, CSS, JavaScript, Angular) and Open API/Swagger.
    
*   Experience with code productivity, diagnostic, quality, and testing tools (ReSharper, CodeRush, NCrunch, Splunk, Dynatrace).
    
*   IAM familiarity and secure software development practices for strengthening application security and compliance.
    
*   Strong debugging skills and ability to handle live issues.
    
*   Customer service focus and collaborative mindset.
    
*   Preferred: Experience in FinTech industry.
