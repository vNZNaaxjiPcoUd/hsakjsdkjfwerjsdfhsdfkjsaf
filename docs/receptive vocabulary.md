# 美國本土英語母語的小學生與中學生，平均認識的英文單字量


美國本土英語母語的小學生與中學生，平均認識的英文單字量（receptive vocabulary，被動理解的單字，通常包含聽說讀）大約如下：

（這些數字是研究與教育界較常引用的**平均值**，實際會因家庭背景、閱讀量、地區差異而有很大差距，差距可達數千甚至上萬字）

| 年級          | 年齡約     | 平均認識單字量（約）       | 備註說明                                                                 |
|---------------|------------|----------------------------|--------------------------------------------------------------------------|
| 1年級         | 6–7歲      | 2,500–5,000               | 剛開始正式大量學閱讀，基礎單字快速累積                                 |
| 3年級         | 8–9歲      | 8,000–12,000              | 很多研究指出約10,000字左右是最常見的平均數字                             |
| 小學畢業 (5–6年級) | 10–12歲    | 13,000–18,000             | 閱讀能力開始分化，愛閱讀的孩子可能遠超這個數字                           |
| 中學7年級     | 12–13歲    | 18,000–25,000             | 進入中學後單字成長速度加快                                               |
| 中學畢業 (8年級) | 13–14歲    | 22,000–30,000（常見25,000）| 許多教育文獻把25,000字視為中學階段的典型平均值                           |

### 常見的參考說法總整理（美國母語學生）
- 3年級結束 ≈ **10,000** 字
- 8年級結束 ≈ **25,000** 字
- 高中畢業 ≈ **40,000–50,000** 字（受過大學教育成人約 **42,000–60,000+**）

這些數字大多是**詞根家族（word families）**或**字典單字（dictionary words）**的估計，實際「出現過並認識」的單字型態（不同詞形變化）會更多。

### 跟台灣學生比較（粗略參考）
台灣小學畢業：課綱要求約300–800字，實際會的常在1,500–3,000字左右  
國中畢業：課綱約1,200–2,000字，實際會的常在3,000–5,000字  
→ 跟美國同齡母語學生相比，單字量差距通常在 **5–10倍** 左右（但台灣學生在文法、閱讀理解深度上常有不同優勢）

總結一句話：

**美國小學生（小學中高年級）大概記得1–1.8萬字，中學生（國中階段）大多落在2–3萬字左右**，而這只是「認識」的被動單字量，他們真正會靈活使用的單字（主動詞彙）通常只有這個數字的1/3～1/2。

## 美國**大學生**（本科階段，約18–22歲，native English speakers）的英文單字量（主要是**被動詞彙/receptive vocabulary**，也就是「認識、能理解」的單字）根據不同研究與計算方式，有相當大的範圍差異。

以下是目前最常見、可靠的研究結論整理（以2020年代後的視角為主，參考Brysbaert 2016大規模研究及其他近期資料）：

| 階段 / 年齡          | 平均認識單字量（約）              | 計算單位說明                              | 常見來源 / 備註                                                                 |
|-----------------------|-----------------------------------|-------------------------------------------|---------------------------------------------------------------------------------|
| 大一新生（18歲左右）  | 35,000–42,000                    | lemmas（基本詞形，不含變化形）            | Brysbaert et al. (2016) 大型眾包研究，20歲平均42,000 lemmas                   |
| 大學畢業（22歲左右）  | 40,000–48,000                    | lemmas / dictionary words                 | 同上研究 + 後續成長；大學教育會加速累積                                        |
| 大學生整體（大學期間）| 38,000–45,000（中位數）          | lemmas                                    | 多數現代研究共識，受教育程度影響大                                              |
| 詞根家族（word families）| 11,000–17,000                  | word families（包含衍生詞如happy/happiness）| Nation & Goulden 等傳統估計；較保守，常用於語言教學                             |
| 主動使用單字（productive）| 15,000–25,000                 | 日常真正會說/寫的單字                     | 被動詞彙的約1/2～2/3；大學生通常更高                                            |

### 最主流的現代說法（2016–2025年研究共識）
- 平均**20歲美國本土大學生**認識約 **42,000** 個**字典單字（lemmas）**（Brysbaert et al., 2016，前沿心理學期刊，大規模上百萬人測試）
  - 這數字不含專有名詞、多詞片語、純變化形（如run/running視為同一個）
  - 範圍：最低5%的人約27,000，最高5%的人超過51,000
- 大學畢業後到60歲，平均再增加約 **6,000** 個，變成 **48,000** 左右
- 如果用比較傳統的「word families」計算（語言學家Paul Nation常用），大學生大概落在 **13,000–17,000** 個word families，相當於認識40,000+個實際出現的詞形變化

### 跟之前階段比較（快速回顧）
- 小學畢業（12歲）：約10,000–13,000 word families
- 高中畢業（18歲）：約13,000–22,000 word families（或30,000–40,000 lemmas）
- 大學階段：明顯再跳一級，來到 **40,000+ lemmas**，這也是為什麼很多人說「大學教育讓詞彙量大幅提升」

### 跟台灣大學生比較（粗略）
台灣大學生（非母語）：
- 一般科系：被動單字約 **6,000–12,000**（頂尖大學英文系可能到15,000+）
- 差距仍大（約3–6倍），但在學術寫作、文法精準度、邏輯表達上，台灣學生常有自己的優勢

總結一句話：

**美國大學生（本土母語）平均認識的英文單字量大約落在 40,000–45,000 個左右（以字典單字/lemmas計）**，這是目前最被接受的現代估計值，受閱讀量、專業領域、家庭背景影響很大。真正每天用到的主動單字則大概只有這個數字的1/2～2/3。

## 美國大學的**電腦科學碩士（MS in Computer Science）** 對國際學生（非英語母語者）的**英文程度要求**，主要是為了確保你能順利跟上課程、寫報告、參與討論、做presentation，甚至當TA（教學助理）。

這不是單看單字量，而是透過標準化考試來證明整體英文能力（聽、說、讀、寫）。以下是2025–2026年最新的主流要求總結（基於頂尖到中上大學的實際數據）：

### 常見英文能力考試最低門檻（國際學生適用）

| 考試類型          | 最低要求（一般大學）          | 競爭性強/頂尖大學（如CMU、Stanford、Berkeley、UIUC、Georgia Tech等） | 備註說明                                                                 |
|-------------------|-------------------------------|-----------------------------------------------------------------------|--------------------------------------------------------------------------|
| **TOEFL iBT**    | 80–90                        | 100+（有些部門要求Speaking 22–27+）                                  | 最常見的考試；Georgia Tech要求100，UCSD 85，Virginia 90，UT Dallas 80 |
| **IELTS Academic**| 6.5 overall（各科不低於6.0） | 7.0–7.5 overall（Speaking常要求7.0+）                                | 很多學校接受；Cornell專業碩士7.0，頂尖常要7.0+                           |
| **Duolingo English Test (DET)** | 110–120                   | 120+                                                                 | 越來越多學校接受（疫情後流行），但頂尖校較少認可或要求更高               |
| **PTE Academic** | 58–65                        | 65+                                                                  | 少數學校接受                                                             |

- **豁免條件**（不用考）：  
  - 在英語為官方語言的國家（如美國、英國、澳洲、加拿大、紐西蘭等）完成學士學位（全英語授課）。  
  - 有些學校接受「Medium of Instruction」證明（本科全英語授課），但越來越多頂尖校不認，只認在英語國家完成學位。

### 不同層級大學的實際範例（2025–2026年）
- **頂尖校（Top 10–20）**：如MIT、Stanford、CMU、Berkeley、UIUC  
  → TOEFL 100+ 或 IELTS 7.0–7.5（Speaking常要高分，因為要當TA）  
- **很好但競爭激烈校**：如Georgia Tech、UT Austin、UCSD、Washington  
  → TOEFL 90–100 或 IELTS 7.0  
- **中上到一般校**：如很多州立大學、NYU Tandon、UT Dallas  
  → TOEFL 80–90 或 IELTS 6.5

### 實際上需要的「英文程度」大概是什麼水平？
- **閱讀**：能快速讀懂學術論文、技術文件（相當於認識8,000–12,000+個學術/專業單字，包括CS領域術語）。
- **聽力**：聽懂教授快速講課、seminar、group discussion（美式口音、技術內容）。
- **寫作**：寫research proposal、SOP、報告、論文（邏輯清晰、學術英文）。
- **口說**：presentation、答辯、跟教授/同學討論code、project（流利度最關鍵，尤其是TA）。

粗略對應：要順利讀完美國CS碩士，**被動單字量**大概需要 **10,000–15,000+** 個（含大量CS專業詞），主動使用（說寫）至少 **6,000–10,000** 個以上。  
→ 這遠高於台灣大學畢業生的平均（6,000–12,000被動），所以多數台灣申請者都需要準備TOEFL/IELTS。

### 建議
- **目標分數**：想衝頂尖校 → TOEFL 105+ / IELTS 7.5+（Speaking 7.0+最保險）。
- **現在準備**：CS碩士申請除了GPA、背景、SOP、推薦信，英文分數是硬門檻，低分常被直接刷掉。
- 有些學校Fall 2026開始TOEFL計分方式有變（新量表），但目前主流還是舊的0-120分。

# **42,000 個字典單字（lemmas）的完整列表**，實際上**不存在公開的免費完整版**，因為這個數字來自2016年Brysbaert et al.的研究（大型眾包測試，基於超過百萬人參與的詞彙辨識實驗），他們使用的62,000個詞列表是用來測試的刺激詞（stimuli），但**原始完整列表並未公開發布**（研究者提到避免版權問題，自行彙整而不依賴特定字典）。

這個42,000是**平均值**（20歲美國母語者認識的lemmas數），範圍從約27,000到51,700不等，不是一個固定、官方的「字典」列表。研究團隊後續擴展到更多詞（English Crowdsourcing Project，現在超過62,000詞），但完整raw list仍限於研究使用，無法直接下載完整42k版。

### 最接近的公開可用大型lemmas列表（免費下載，接近或超過40,000）
以下是目前最可靠、公開的替代方案（基於大型語料庫如COCA、SUBTLEX等，聚焦lemmas/base forms，不含專有名詞或太多變形）：

1. **COCA Top 60,000 Lemmas（最推薦，接近42k水平）**  
   - 來源：Corpus of Contemporary American English (COCA)，美國當代最大平衡語料庫。  
   - 提供top 60,000 lemmas（包含頻率、dispersion等資訊）。  
   - 免費下載：http://www.wordfrequency.info/files/wordlist_60k.xls （Excel格式，每7個詞取樣，但完整版需購買；免費樣本已很實用）  
   - 為什麼接近？COCA lemmas列表是現代研究中最常參考的，涵蓋日常到學術詞，平均母語成人認識的很大部分就在前40–50k內。

2. **Brysbaert concreteness norms（37,000+ lemmas）**  
   - 2014年Brysbaert團隊發布的37,058個一般已知English lemmas（加上2,896個multiword），附concreteness評分。  
   - 這是他們2016年42k估計的子集（只包含至少85%的人認識的詞）。  
   - 下載：可在ResearchGate或Springer搜"Concreteness ratings for 40 thousand generally known English word lemmas"，常有PDF附表或數據連結（免費學術下載）。

3. **其他大型公開word lists（lemmas或近似，40k+）**  
   - GitHub dwyl/english-words：479,000+ words（包含大量lemmas，但混雜變形和罕見詞；words_alpha.txt是最乾淨的字母排序列表）。  
     → https://github.com/dwyl/english-words  
   - 12dicts項目（Kevin Atkinson）：有lemmatized very large lists（如2+2+3lem，超過數十萬，但可過濾到常見40k）。  
     → http://wordlist.aspell.net/12dicts  
   - Wiktionary frequency lists：top 60,000 lemmas sampled from COCA（免費頁面可瀏覽/下載部分）。  
     → https://en.wiktionary.org/wiki/Wiktionary:Frequency_lists/English

|---------------------------|----------------|--------------|--------|-----------------------------|------------------------------------|

### 結論與建議
- **沒有一個公開的「正好42,000個」完整列表**，因為它是統計平均，不是固定字典。  
- 如果你想練習或測試接近這個水平的詞彙，建議從**COCA 60k**或**Brysbaert 37k**開始（前者更全面，後者更聚焦「一般人認識」的詞）。  
- 想自己建一個？可以用Python從GitHub下載大列表 + lemmatize（用nltk/spacy），過濾頻率高的前40–50k。  
- 如果你需要特定領域（如CS、學術）、或想測自己的詞彙量，推薦直接去http://vocabulary.ugent.be/ 做Brysbaert團隊的在線測試（免費，會估計你的個人大小）！
