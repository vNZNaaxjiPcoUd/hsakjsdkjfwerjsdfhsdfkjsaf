
# **Fidelity**
（全稱 **Fidelity Investments**，中文常稱**富達投資**或**富達證券**）是美國最大的資產管理與券商公司之一，成立於1946年，總部位於波士頓，目前管理數兆美元資產，是全球頂級金融機構。

### Fidelity 是什麼？
簡單來說，它是一家「全方位金融服務公司」，主要業務包括：
- 個人投資帳戶（證券戶）
- 退休帳戶（IRA、401(k)、Roth IRA 等）
- 共同基金（Mutual Funds）與 ETF（自家發行很多零費用指數基金）
- 財富管理 / 理財顧問服務
- 現金管理帳戶（CMA，像高息支票帳戶）
- 529 教育儲蓄計劃、HSA 醫療儲蓄帳戶
- 比特幣 / 以太幣現貨 ETF（FBTC 是市場上規模最大的比特幣 ETF 之一）
- 企業退休計劃（幫公司設立 401(k)）

它同時適合「被動長期投資者」和「想要主動交易的人」。

### Fidelity 的主要特色與優勢（2026 年最新觀點）
以下是它最常被稱讚、也最有競爭力的地方：

1. **交易完全免手續費 + 零帳戶管理費**  
   美股、ETF、選擇權（每張合約約 $0.65）幾乎全免，沒有隱藏費用。

2. **零費用比率指數基金非常多**  
   Fidelity 有大量費用比率 0% 的指數基金（比 Vanguard 還多一些選擇），長期持有成本極低。

3. **分數股（Fractional Shares）超方便**  
   1 美元起就能買到像 NVDA、TSLA 這種高價股，適合小額投資或定期定額。

4. **現金管理帳戶（CMA）很強**  
   - 像高息支票 + 儲蓄帳戶的混合體  
   - 全球 ATM 手續費全額退還（無限次）  
   - 目前收益率通常很有競爭力  
   - 很多人直接拿來當日常花費帳戶用

5. **研究工具與教育資源豐富**  
   - Active Trader Pro（專業交易平台）功能強大  
   - 免費的財經新聞、分析師報告、股票篩選器、退休規劃計算器  
   - 適合想自己研究的人

6. **退休與稅務帳戶彈性高**  
   - Roth IRA 轉換、 rollover 流程順暢  
   - HSA 帳戶投資功能很好（三重稅務優勢）

7. **加密貨幣布局早且規模大**  
   2024 年推出的 FBTC（比特幣現貨 ETF）管理資產已非常龐大，2026 年仍是市場主流選擇之一。

8. **客戶服務評價高**  
   電話、線上聊天、實體分行（美國很多城市有）反應快，很多人覺得比 Schwab 或 Vanguard 更親切。

## **Fidelity（富達投資）開戶流程、手續費細節，以及與其他券商的最新比較**（基於2026年1月最新資訊）

### 1. 開戶流程（Fidelity Brokerage Account）
Fidelity 的開戶過程非常簡單，全線上完成，通常只需 **10-20 分鐘**（視個人資料完整度而定）。美國居民（含 Miami 等地）可直接操作；非美國居民（如台灣/香港）需確認是否支援（Fidelity 對部分國際客戶有限制，可能需額外文件或使用 Fidelity International 分支）。

**步驟大致如下**：
1. 前往官網：https://www.fidelity.com/open-account/overview 或直接點擊「Open an Account」。
2. 選擇帳戶類型：
   - Brokerage（一般證券戶，最常見）
   - IRA（傳統/ Roth 退休帳戶）
   - HSA、529、CMA（現金管理帳戶）等
   - 個人、聯合、信託等
3. 填寫個人資訊：
   - 姓名、地址、電話、email
   - SSN（美國社安號）或 ITIN（若適用）
   - 出生日期、就業資訊、財務狀況（收入、淨資產等，用於風險評估）
   - 投資經驗、目標
4. 身分驗證：上傳駕照/護照、社安卡等（或系統自動驗證）。
5. 設定資金來源：連結銀行帳戶（ACH 轉帳免費）、電匯，或之後再入金。
6. 同意條款、電子簽名，提交申請。
7. 審核：大多數當天或 1-3 個工作日內完成（若需郵寄文件，可能 3-5 天）。

**所需文件**：通常只需 SSN + 身分證明；無最低開戶金額（$0 起開戶，$1 起即可投資分數股）。

**小Tips**：用手機 App 開戶一樣順暢，很多人在 2026 年直接用 App 完成。開戶後可立即開始交易（資金到帳前也能看盤、下單）。

### 2. 手續費細節（2026 年最新）
Fidelity 維持極低費用結構，幾乎所有常見交易都免費。

- **股票 / ETF**：線上美國股票、ETF 交易 → **$0 佣金**（無最低金額限制）。
- **選擇權（Options）**：$0 基底 + **$0.65 / 每張合約**（買入平倉 ≤ $0.65 時免費）。
- **共同基金**：
  - Fidelity 自家基金 → 買賣 $0。
  - 零交易費（NTF）非自家基金 → 買入 $0，持有 <60 天賣出 $49.95。
  - 有交易費基金 → 買入 $49.95（部分 $75-$100），賣出 $0。
- **債券 / CD**：
  - 新發行（New Issues）→ $0。
  - 二級市場 → $1 / 債券（最低 $19.95-$250 上限，視情況）。
  - 美國國債 → 線上 $0。
- **Margin 融資利率**：依餘額階梯，最低可到 **7.50%**（$1M+ 餘額），$0-$24,999 為 11.825% 左右。
- **帳戶費用**：$0 帳戶維護費、$0 月結單、$0 轉帳費（ACH/EFT）、$0 ATM 境外手續費退還（CMA 帳戶）。
- **其他常見**：
  - 電匯（國內）→ $0。
  - 外幣電匯 → 最高 3%。
  - 資產轉入/出 → $0（ACATS）。
  - 外國股票結算費（非 DTC）→ $50 / 筆。
  - 無隱藏帳戶最低餘額費、無 IRA 關閉費等。

總結：對一般投資者來說，**日常交易成本接近 $0**，非常透明。
