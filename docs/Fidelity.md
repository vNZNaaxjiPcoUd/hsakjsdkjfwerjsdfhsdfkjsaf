
# **Fidelity**
（全稱 **Fidelity Investments**，中文常稱**富達投資**或**富達證券**）是美國最大的資產管理與券商公司之一，成立於1946年，總部位於波士頓，目前管理數兆美元資產，是全球頂級金融機構。

### Fidelity 是什麼？
簡單來說，它是一家「全方位金融服務公司」，主要業務包括：
- 個人投資帳戶（證券戶）
- 退休帳戶（IRA、401(k)、Roth IRA 等）
- 共同基金（Mutual Funds）與 ETF（自家發行很多零費用指數基金）
- 財富管理 / 理財顧問服務
- 現金管理帳戶（CMA，像高息支票帳戶）
- 529 教育儲蓄計劃、HSA 醫療儲蓄帳戶
- 比特幣 / 以太幣現貨 ETF（FBTC 是市場上規模最大的比特幣 ETF 之一）
- 企業退休計劃（幫公司設立 401(k)）

它同時適合「被動長期投資者」和「想要主動交易的人」。

### Fidelity 的主要特色與優勢（2026 年最新觀點）
以下是它最常被稱讚、也最有競爭力的地方：

1. **交易完全免手續費 + 零帳戶管理費**  
   美股、ETF、選擇權（每張合約約 $0.65）幾乎全免，沒有隱藏費用。

2. **零費用比率指數基金非常多**  
   Fidelity 有大量費用比率 0% 的指數基金（比 Vanguard 還多一些選擇），長期持有成本極低。

3. **分數股（Fractional Shares）超方便**  
   1 美元起就能買到像 NVDA、TSLA 這種高價股，適合小額投資或定期定額。

4. **現金管理帳戶（CMA）很強**  
   - 像高息支票 + 儲蓄帳戶的混合體  
   - 全球 ATM 手續費全額退還（無限次）  
   - 目前收益率通常很有競爭力  
   - 很多人直接拿來當日常花費帳戶用

5. **研究工具與教育資源豐富**  
   - Active Trader Pro（專業交易平台）功能強大  
   - 免費的財經新聞、分析師報告、股票篩選器、退休規劃計算器  
   - 適合想自己研究的人

6. **退休與稅務帳戶彈性高**  
   - Roth IRA 轉換、 rollover 流程順暢  
   - HSA 帳戶投資功能很好（三重稅務優勢）

7. **加密貨幣布局早且規模大**  
   2024 年推出的 FBTC（比特幣現貨 ETF）管理資產已非常龐大，2026 年仍是市場主流選擇之一。

8. **客戶服務評價高**  
   電話、線上聊天、實體分行（美國很多城市有）反應快，很多人覺得比 Schwab 或 Vanguard 更親切。

### 跟其他大券商簡單比較（2026 年觀點）

| 項目              | Fidelity                  | Vanguard                  | Charles Schwab            |
|-------------------|---------------------------|---------------------------|---------------------------|
| 交易費用          | 免費                      | 免費                      | 免費                      |
| 零費用基金數量    | 非常多                    | 多（但較專注自家）        | 中等                      |
| 分數股            | $1 起                     | 有（但限制較多）          | 有                        |
| 現金管理帳戶      | 極強（CMA）               | 普通                      | 強（高息 checking）       |
| 主動交易工具      | 很強                      | 較弱                      | 中等偏強                  |
| 研究 / 教育資源   | 非常豐富                  | 中等                      | 豐富                      |
| 最適合對象        | 想兼顧被動＋主動、要好用工具的人 | 極度低成本、純被動長期    | 想一站式銀行＋投資的人    |

總結一句話：  
**Fidelity 是「功能最全面、工具最友善、成本又很低」的美國券商**，特別適合：
- 同時想買基金＋個股＋分數股的人
- 需要強大研究工具與規劃器的人
- 想要把投資＋日常現金管理結合起來的人
- 對加密貨幣有興趣的人

如果你是台灣／香港投資者想開美股戶，很多人都把 Fidelity 列為前三名推薦（跟 IBKR、Schwab 並列）。
