# 美國槍枝法規

佛羅里達州（Florida，簡稱佛州）是美國槍枝法規最寬鬆的州之一，尤其在2023年後實施「permitless carry」（無需許可攜帶），並在2025年發生重大變化：**公開攜帶（open carry）** 已部分合法化。

以下是截至2026年初（2025年最新情況）的佛州槍枝主要規定概述（基於佛州法典Chapter 790及近期法院裁決與立法變化）：

### 1. 隱藏攜帶（Concealed Carry）
- 自**2023年7月1日**起，佛州實行**permitless concealed carry**（無需許可隱藏攜帶）。
- 符合條件的人可以**直接隱藏攜帶槍枝**（手槍、長槍隱藏部分適用），無需申請Concealed Weapon or Firearm License（CWFL）。
- 基本條件（21歲以上、非重罪犯、無特定精神病史、不是非法移民等）。
- 即使不申請許可，建議攜帶有效身分證件（駕照等），因為執法時需證明身分。
- 如果有CWFL許可，仍然有效，且可享有互助州（reciprocity）優惠、在某些場所多一點權利。

### 2. 公開攜帶（Open Carry） — 2025年重大變化
- 過去數十年，佛州原則上禁止公開攜帶手槍（open carry ban）。
- **2025年9月**，佛州第一上訴法院裁定長期公開持槍禁令**違憲**（違反第二修正案）。
- 州檢察長隨後指示執法機關不再全面執法該禁令。
- 自**2025年9月25日**起，**公開攜帶合法**（守法成年公民可在公共場所公開攜帶手槍/左輪手槍）。
- 但仍有許多**限制場所**（仍禁止公開攜帶）：
  - 學校、校園及周邊
  - 法院、檢察署、監獄
  - 機場安檢區
  - 投票所（選舉日）
  - 酒吧（主要賣酒場所）
  - 政府大樓（部分）
  - 私人場所（商家、餐廳、公司、HOA社區可禁止）
  - 任何張貼「No Firearms」或「No Weapons」標誌的私人財產

### 3. 購買槍枝規定
- 購買手槍、長槍**無需州級許可**。
- 聯邦背景調查（NICS）仍然強制執行（槍店購買）。
- 私人間轉讓（私人賣槍）**不需要背景調查**（但買方仍需符合持有資格）。
- 年齡要求：
  - 手槍：21歲以上（聯邦法）
  - 長槍：18歲以上
- 無等待期（waiting period）。

### 4. 禁止持有槍枝的人
- 重罪犯（felon）
- 家庭暴力輕罪定罪者
- 有特定精神健康強制令者
- 非法移民
- 某些吸毒或家暴保護令對象
- 未滿18歲（某些例外）

### 5. 其他重要規定（2025–2026適用）
- **校園**：校園內仍嚴格禁止（除非特定執法人員或許可持有者）。
- **Stand Your Ground**（自衛不退讓法）：佛州有強大的自衛法律，無義務退讓。
- **槍枝在車內**：可放在車內隱藏或公開（符合條件下），但建議隱藏較安全。
- **商家權利**：私人企業、餐廳、超市、公寓社區可張貼禁止槍枝標誌，違者可被視為擅闖。
- **非居民**：其他州有許可的人可在佛州攜帶（互助），2025年起無許可州居民也可依permitless規則。

佛州槍枝法規非常寬鬆，被視為全美最友善槍枝州之一，但**公開攜帶**仍有很多實際限制與灰色地帶，執法時容易引起爭議。建議：
- 出門攜帶時務必攜帶身分證明。
- 避免敏感場所。
- 商家/場所標誌要尊重。
- 如有疑問，最好參考佛州官方立法網站（leg.state.fl.us）Chapter 790，或諮詢當地律師/警局。

## 佛羅里達州（Florida）對**槍枝種類**的限制主要遵循**聯邦法**（尤其是National Firearms Act, NFA）和州法（Florida Statutes Chapter 790），州級並沒有額外的「assault weapons ban」或特定半自動步槍禁令。佛州槍枝法規整體非常寬鬆，允許大多數常見民用槍枝（手槍、AR-15式步槍、AK式等），但對某些「NFA項目」和特殊武器有嚴格禁止或聯邦管制。

以下是截至2026年（基於2025 Florida Statutes Chapter 790及相關更新）的**槍枝種類限制規定**概述：

### 1. 完全禁止或嚴格限制的槍枝種類（州法禁止持有，除非特殊例外）
- **機槍（Machine Guns）**：自動射擊武器（單扣扳機可連發多發）。  
  州法（s. 790.221）禁止任何人擁有、持有或控制可運作的機槍 → **二級重罪（felony）**。  
  例外：僅限聯邦註冊的NFA持有者（需向ATF繳稅、背景調查、等待批准，通常數月至一年），且需符合聯邦法。佛州不額外發許可。
- **短管步槍（Short-Barreled Rifles, SBR）**：槍管<16英寸，或整體長度<26英寸的步槍（包括改裝後符合者）。  
  州法同樣禁止（s. 790.221）→ **重罪**。
- **短管散彈槍（Short-Barreled Shotguns, SBS）**：槍管<18英寸，或整體長度<26英寸的散彈槍。  
  同上，禁止持有。
- **破壞性裝置（Destructive Devices）**：炸彈、手榴彈、火箭筒、毒氣裝置、口徑≥0.5英寸的某些大口徑武器（非狩獵用散彈槍除外）。  
  製造、持有、使用、威脅使用 → 重罪，甚至可達死刑級（若造成死亡）。
- **其他明確禁止的武器/配件**：
  - **Bump-fire stocks**（衝擊式槍托）：禁止擁有、銷售、轉讓（s. 790.222）→ 三級重罪。
  - **彈道自推進刀（Ballistic self-propelled knives）**：禁止製造、銷售、擁有。
  - **穿甲彈、爆炸彈、龍息彈（Dragon’s Breath）、bolo彈、flechette散彈**：禁止製造、銷售、持有（s. 790.31）。
  - **金屬指節（Metallic knuckles）、甩棍（slungshot）、dirk刀等**：部分禁止製造/銷售。

### 2. 沒有州級禁令的常見槍枝種類（合法持有/購買/攜帶）
佛州**沒有**「assault weapons」禁令，也**沒有**高容量彈匣（large-capacity magazine）限制或「feature-based」禁令（如無折疊槍托、握把、閃光抑制器等）。
- **手槍（Handguns/Pistols）**：包括Glock、Sig Sauer、任何半自動手槍 → 完全合法（21歲以上購買）。
- **步槍（Rifles）**：AR-15、AK-47變體、任何半自動中心火力步槍（即使有「軍用外觀」）→ 合法（18歲以上購買長槍）。
- **散彈槍（Shotguns）**：泵動、半自動散彈槍 → 合法。
- **高容量彈匣**：30發、60發、100發鼓彈匣 → 完全合法，無限制。
- **消音器（Silencers/Suppressors）**：聯邦NFA項目，需ATF批准+稅票，但州法不額外禁止。
- **其他**：槍管≥16英寸的AR步槍、槍管≥18英寸的散彈槍 → 標準合法。

### 3. 聯邦 vs. 州法重點
- 佛州禁止的NFA項目（機槍、SBR、SBS、破壞性裝置）基本上與聯邦一致：如果你有**有效ATF Form 1/4批准**和稅票（$200），聯邦允許擁有，佛州也會承認（s. 790.221有聯邦例外條款）。
- 但大多數佛州居民不會去申請這些，因為程序複雜、昂貴、等待時間長。
- 佛州**沒有**州級的「red flag」以外的額外禁令，也沒有2025–2026年新增的槍枝種類禁令（雖然有民主黨提案想禁assault weapons和高容量彈匣，但尚未通過）。

### 4. Miami（你所在地區）額外注意
- 在Miami-Dade縣或市內，沒有額外的地方禁令覆蓋州法（佛州預占槍枝管制，地方不能更嚴）。
- 但公開攜帶（open carry）在私人場所（如商場、餐廳）仍取決於業主標誌；學校、機場、法院等仍全面禁止任何槍枝。

總結：佛州允許幾乎所有民用半自動槍枝和高容量彈匣，**沒有assault weapon禁令**。真正受限的是NFA類（機槍、短管、消音器需聯邦批准）和上述少數明確禁止項目。如果你想買AR-15、Glock 19、帶30發彈匣的槍 → 完全合法，只需通過聯邦背景調查。
