咸肉和臘肉
========


咸肉和臘肉都是中國傳統的「醃臘肉品」，名字只差一個字，但做法、風味、產地和吃法完全不一樣！下面用一張表直接告訴你差別：

| &#xA;項目&#xA;         | &#xA;咸肉&#xA;                       | &#xA;臘肉&#xA;                                |
| -------------------- | ---------------------------------- | ------------------------------------------- |
| &#xA;英文&#xA;         | &#xA;Salted pork&#xA;              | &#xA;Chinese cured & smoked bacon&#xA;      |
| &#xA;主要做法&#xA;       | &#xA;鹽 + 少量硝（或不加）醃漬 → 低溫風乾或曬乾&#xA; | &#xA;鹽 + 料酒 + 花椒/八角等香料醃漬 → 煙燻（柏樹枝、果木等）&#xA; |
| &#xA;外觀&#xA;         | &#xA;肉色偏白或粉紅，脂肪透明&#xA;             | &#xA;皮金黃、肉深紅或黑紅，切開有明顯煙燻紋&#xA;               |
| &#xA;味道&#xA;         | &#xA;純粹「鹹香」，帶輕微發酵味&#xA;            | &#xA;濃郁「煙燻香」+ 香料味，吃一口像在吃烤肉&#xA;             |
| &#xA;水分&#xA;         | &#xA;較高，口感軟嫩多汁&#xA;                | &#xA;低，肉質緊實有嚼勁&#xA;                         |
| &#xA;代表產地&#xA;       | &#xA;江浙（上海咸肉、蘇州咸肉）、廣東（廣式咸肉）&#xA;   | &#xA;湖南（湘西臘肉）、四川（川味臘肉）、廣東（雲臘肉）、貴州&#xA;      |
| &#xA;經典菜&#xA;        | &#xA;咸肉菜飯、咸肉粽、咸肉百頁、咸肉湯&#xA;        | &#xA;臘肉炒筲箕笋、臘肉蒸土豆、臘肉煲仔飯、臘味合蒸&#xA;           |
| &#xA;保存方式&#xA;       | &#xA;冰箱冷藏 1–2 週&#xA;               | &#xA;掛通風處可放半年到 1 年&#xA;                     |
| &#xA;熱量（每 100g）&#xA; | &#xA;約 400–500 kcal&#xA;           | &#xA;約 550–650 kcal（煙燻更濃縮）&#xA;             |

**快速記憶口訣**

* **咸肉**＝「鹹」＋「鮮」，像加了鹽的鮮五花。
* **臘肉**＝「醃」＋「燻」，像中國版的 BBQ 煙燻培根。

**怎麼挑、怎麼煮？**

1. **買咸肉**：看肉色粉嫩、脂肪雪白，聞起來只有鹹香沒怪味。蒸前先泡水 30 分鐘去鹽。
2. **買臘肉**：皮要金黃乾爽、肉色深紅透亮，用手捏硬硬的。煮前用溫水洗淨，再用米酒或白酒擦一遍去煙味。

**一句話總結**

**咸肉是「鹹鮮系白切肉」，臘肉是「煙燻系黑森林火腿」**——想吃清爽江浙味選咸肉，想吃重口湘川味選臘肉！
下次過年回家，記得跟爸媽說：「我要咸肉蒸春筍，也要臘肉炒臘八蒜！」保證兩道菜都上桌～
