在macOS建立檔案捷徑
==========
以下是目前最常用且最穩定的幾種方法（從 macOS Ventura、Sonoma、Sequoia 都適用）：

### 方法 1：最簡單的「製作別名」（推薦，大多數人都在用）
1. 在 Finder 裡找到你想建立捷徑的檔案。
2. 用滑鼠右鍵點擊該檔案（或按住 Control + 點擊）。
3. 選擇「製作別名」（Make Alias）。
4. Finder 會立刻在同一個資料夾產生一個帶有小箭頭的別名檔案（檔名會自動加上「別名）。
5. 把這個「xxx 別名」檔案直接拖曳或複製到桌面就完成了。

小技巧：
- 你也可以直接按住 Option + Command 鍵，然後把檔案拖曳到桌面，就會直接在桌面上建立別名（不用經過第 3、4 步）。

### 方法 2：右鍵選單直接「加入至側邊欄」或「加入至「書籤」」以外，用「加入至桌面」
macOS Sequoia（15.x）之後，右鍵選單多了這個選項：
1. 右鍵點擊檔案
2. 選擇「加入至桌面」  
   → 系統會自動在桌面上建立一個別名（一樣有小箭頭）

### 方法 3：用符號連結（進階玩家用，沒有小箭頭，看起來更乾淨）
如果你不喜歡別名那個小箭頭，想要完全一模一樣的圖示，可以用終端機建立「符號連結」：

1. 開啟「終端機」（Terminal）
2. 輸入以下指令（把路徑改成你自己的）：

```bash
ln -s /原來檔案的完整路徑 ~/Desktop/你想取的名字
```

範例：要把「文件」資料夾裡的「2025報稅資料.xlsx」建立到桌面

```bash
ln -s /Users/你的帳號名稱/Documents/2025報稅資料.xlsx ~/Desktop/2025報稅資料.xlsx
```

這樣桌面上的圖示就跟原本一模一樣，沒有小箭頭，但功能跟捷徑完全一樣。

### 三種方式比較

| 方式         | 有沒有小箭頭 | 圖示是否跟原檔一樣 | 原始檔移動或改名會不會失效嗎 | 推薦指數 |
|--------------|--------------|----------------------------|------------------------------|----------|
| 製作別名（方法1、2） | 有小箭頭     | 相同                       | 不會失效（很聰明）           | ★★★★★    |
| 符號連結（方法3）   | 沒有         | 完全相同                   | 會失效（路徑斷掉就找不到）   | ★★★      |

99% 的人用「製作別名」就夠了，又簡單又穩。
