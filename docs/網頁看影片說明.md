view youtube and loop 網頁看影片說明
===========

可以使用的功能
1. 可以貼上網址，播放影片
2. 單個影片，不斷重複播放
3. 沒有廣告
4. 可以放大，縮小，以符合螢幕大小
5. 可以關掉瀏覽器，或關掉手機，只播放聲音

使用方法：
1. 使用分享 -> 複製網址
2. 打開此網站
3. 按下 "Fill in your feedback message !"
4. 貼上網址
5. 按下 "換行" "回車" 開始播放。 （不要按打鈎）
6. 播放時，可以畫面直放 或橫放 或放大到全螢幕
7. 在播放中，回到桌面，或關機。再打開控制中心，按下播放，即可以讓它繼續播放聲音。在聽音樂或語言學習，很方便。
8. 重新刷新瀏覽器，即可以重新申入要播放的影片
9. 最下方為此影片的連接，保存可以直接播此影片
