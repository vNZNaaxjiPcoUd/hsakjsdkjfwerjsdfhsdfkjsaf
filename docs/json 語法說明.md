
# JSON 的基本語法說明

JSON (JavaScript Object Notation) 是一種輕量級的資料交換格式，易於人閱讀和編寫，也易於機器解析和生成。

以下是 JSON 的基本語法說明：

### 1. 資料結構 (Data Structure)

JSON 結構基於兩種結構：

*   **物件 (Object):** 鍵值對的集合，用**大括號 `{}`** 包圍，資料以「鍵 (key)」和「值 (value)」的配對形式儲存。
    *   範例：`{"name": "John", "age": 30}`
*   **陣列 (Array):** 有序的值的列表，用**中括號 `[]`** 包圍。
    *   範例：`["apple", "banana", "cherry"]`

### 2. 鍵 (Keys)

*   鍵必須是**字串 (String)**，並且必須用**雙引號 `""`** 括起來。
*   鍵和值之間用**冒號 `:`** 分隔。
*   物件中的每一個鍵值對之間用**逗號 `,`** 分隔。

### 3. 值 (Values)

值可以是以下六種**資料類型**之一：

| 資料類型 | 說明 | 範例 |
| :--- | :--- | :--- |
| **字串 (String)** | 由零個或多個 Unicode 字元組成，必須用**雙引號 `""`** 括起來。 | `"Hello World"` |
| **數字 (Number)** | 整數或浮點數，**不需要**引號。 | `10` 或 `3.14` |
| **物件 (Object)** | 另一個 JSON 物件。 | `{"city": "New York"}` |
| **陣列 (Array)** | 一個值的有序列表。 | `[1, 2, 3]` |
| **布林值 (Boolean)** | 兩個字面值：`true` 或 `false`（**小寫**，無引號）。 | `true` |
| **空值 (Null)** | 表示空值，字面值為 `null`（**小寫**，無引號）。 | `null` |

### 4. 完整範例

這是一個包含物件、陣列和不同資料類型的 JSON 範例：

```json
{
  "firstName": "Jane",
  "lastName": "Doe",
  "isEmployed": true,
  "age": 28,
  "spouse": null,
  "phoneNumbers": [
    {
      "type": "home",
      "number": "555-1234"
    },
    {
      "type": "work",
      "number": "555-5678"
    }
  ],
  "address": {
    "street": "123 Main St",
    "city": "Anytown"
  }
}
```

### 總結重點：

1.  **所有鍵 (Keys) 必須是雙引號括起來的字串。**
2.  **所有字串值 (String Values) 必須是雙引號括起來的。**
3.  數字、布林值 (`true`/`false`) 和 `null` 不需要引號。
4.  物件使用 `{}`，陣列使用 `[]`。
5.  鍵和值之間用 `:` 分隔。
6.  物件內的每個鍵值對之間用 `,` 分隔。
7.  陣列中的元素之間用 `,` 分隔。
