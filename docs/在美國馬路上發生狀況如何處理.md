# 在美國馬路上發生狀況如何處理
在美國佛羅里達州（Florida）如果在馬路上發生車禍（car accident），不管是大撞、小擦傷還是單獨撞到路邊，處理方式大致如下，我用最實用的步驟告訴你：

### 1. 先確保安全（最重要！）
- 盡量把車移到路邊或安全的地方，避免堵在馬路中間。
- 打開警示燈（Hazard lights）。
- 如果有人受傷或車子完全動不了，馬上打911。

### 2. 什麼情況一定要報警？
佛州法律規定以下情況「必須」報警（Must call police）：
- 有人受傷（不管輕重）
- 有人酒駕或藥駕嫌疑
- 有人想逃逸（Hit and run）
- 政府公家車（警車、公車、校車等）被撞
- 總損失看起來超過 $500（這個最常見，很多保險公司也要求有警察報告才理賠）

如果只是很小的擦傷、雙方都同意、私了，而且沒有人受傷、沒喝酒，可以選擇不報警，但建議還是報，拿警察報告比較保險。

### 3. 怎麼找警察？
- 直接打 911（全美國通用，佛州也一樣）
- 或者打非緊急電話：*FHP（*347）  
  → 這是 Florida Highway Patrol（州際公路巡警）的快捷號，在手機上直接撥 *FHP 就會轉接到最近的州警。
- 如果在城市裡（像 Miami, Orlando, Tampa），也可以打當地警察局的非緊急電話，例如：
  - Miami-Dade Police: 305-476-5423
  - Orange County (Orlando): 407-836-4357
  - 但最快還是直接打 911 或 *FHP

### 4. 警察來之前你要做的事（很重要！）
- 拍照：兩台車的車牌、撞擊位置、四個角全貌、駕照、保險卡
- 交換資訊（對方不給也沒關係，你拍照就好）：
  - 對方姓名、電話
  - 車牌號碼
  - 駕照號碼
  - 保險公司名稱 + 保單號碼（Policy number）
- 找目擊證人（如果有的話）
- 不要當場承認「是我的錯」（說 I’m sorry 也盡量避免），因為會影響保險理賠

### 5. 警察來了會怎麼做？
- 他們會做一份「Florida Crash Report」
  - 有分 Long Form（比較嚴重）跟 Short Form（小事故）
  - 報告上會有「Case Number」，保險公司會問你要這個
- 你可以在 10 天內去 Florida Highway Safety 網站下載報告：
  https://www.flhsmv.gov/traffic-crash-reports/

### 6. 常見的佛州小提醒
- 佛州是 No-Fault 州：你先用自己的 PIP（Personal Injury Protection，$10,000）看醫生，不管誰錯。
- 如果對方完全沒保險（佛州很多這種人），你要靠自己的 UM/Uninsured Motorist 保險。
- Hit and run（撞了就跑）在佛州罰很重，對方如果跑了，你一定要報警拿報告，不然保險公司不理賠。

### 一句話總結（你只要記得這三個號碼）
- 有人受傷 → 911
- 一般車禍想找州警 → *FHP（*347）
- 在市區 → 也可以打 911 讓接線員幫你轉當地警察


## 下面是佛羅里達州（Florida）車禍後保險理賠的完整實戰流程，2025 年還是這樣走，99% 的案例都適用：

### 第一階段：事故當下～3 天內（越快越好）
1. 報警拿 Case Number（警察報告編號）  
   → 沒有警察報告，很多保險公司會故意拖你。
2. 24～48 小時內打電話向「自己」的保險公司報案  
   （即使你完全沒錯，也一定要先報自己的保險！因為佛州是 No-Fault 州）
   - 需要提供的資訊：
     - 你的保單號碼（Policy number）
     - 事故日期、地點、警察 Case Number
     - 對方車牌、姓名、保險公司（如果有拿到）
3. 同時打電話向「對方」的保險公司也報案  
   （這一步很多人忘記，做了會快很多）

### 第二階段：醫療部分（PIP 跟 Bodily Injury）
佛州強制每台車都有 PIP $10,000（Personal Injury Protection）
1. 14 天內看醫生（超商診所、急診、整脊都行）  
   → 超過 14 天，PIP 整張 $10,000 就作廢！（這是佛州最坑的規定）
2. 看完醫生把帳單跟報告寄給「自己的保險公司」，他們會直接付 80%（剩下的 20% 可以用健保或自付）
3. 如果醫療費用超過 $10,000，或有「永久性傷害」（骨折、疝氣、永久疤痕等），你就可以告對方，拿 Bodily Injury（BI）賠償  
   → 這時候就要找律師了（佛州車禍律師都是免費先談，贏了才抽 33～40%）

### 第三階段：車子修理（Property Damage）
兩種情況：

A. 對方全責或主要責任（最常見）  
   → 直接用對方保險修車  
   流程：  
   1. 對方保險公司會打給你確認事故經過  
   2. 他們派估價員（Adjuster）來看車，或叫你去他們配合的車廠  
   3. 同意賠償金額後，你可以選擇：
      - 拿支票自己修
      - 讓他們指定車廠修（通常比較快）

B. 你自己有錯、對方沒保險、或 Hit-and-run  
   → 用你自己的 Collision（綜合險/全險）或 UM/PD（Uninsured Motorist Property Damage）  
   → 要先付 Deductible（自負額，通常 $500 或 $1,000），之後抓到對方或 Hit-and-run 抓到人可以拿回來。

### 第四階段：拿錢結案（Settlement）
常見賠償項目：
1. 車子修理費或殘值（Total loss）
2. 租車費（Rental car，大概每天 $30～45，對方保險最多付 30 天）
3. 醫療費（超過 PIP 的部分）
4. 失工費（Miss work）
5. 疼痛與精神損害（Pain & Suffering）← 這筆才是大錢，通常是醫療費的 1～5 倍

結案時保險公司會寄一張「Release 釋放書」給你簽，簽了就不能再告了，所以：
- 千萬不要在還在治療時就簽！
- 最好找律師看一下，或至少等所有治療結束、醫生給你 MMI（Maximum Medical Improvement）報告再談。

### 佛州車禍理賠時間表（實際經驗值）
- 小撞（只有車損）：2～6 週拿完錢
- 有受傷但不嚴重：2～6 個月
- 骨折、手術、需要律師：8～18 個月（律師案子通常拿比較多）

### 一句話總結佛州理賠順序
1. 先報自己保險（24 小時內）  
2. 14 天內看醫生（保住 PIP $10,000）  
3. 車子用對方保險修  
4. 傷勢嚴重就找律師，其餘自己跟保險公司談

## 佛羅里達州 PIP（Personal Injury Protection）保險超級重要，也是全美最坑、最嚴格的規定之一。2025 年還是完全沒變，以下是100%實用的完整細節：

### 佛州 PIP 基本硬性規定（法律強制）
- 每台註冊在佛州的車「必須」至少買 $10,000 PIP + $10,000 PDL（後面會講）
- 沒有 PIP → 車子不能上路、不能年檢、被抓到直接吊牌+罰款
- PIP 屬於 No-Fault：不管誰撞誰，醫療費先從「自己的 PIP」出

### PIP 涵蓋範圍（到底賠什麼？）
1. 醫療費用 → 80%（包含醫院、急診、復健、整脊、針灸、按摩）
2. 失工薪資 → 60%（最多連續賠 3 年，但實際上很少用到這麼久）
3. 死亡給付 → $5,000 喪葬費（車上每個人都有）
4. $5,000 死亡保險（如果事故中當場死亡）

### 最坑的「14 天規定」（超過就全軍覆沒！）
- 事故後 14 天內「一定要」看醫生、診所、急診、整脊都算  
  （哪怕只是去簽個到、拿個診斷書也行）
- 第 15 天才去看 → 整張 $10,000 PIP 直接作廢！保險公司一分錢都不賠
- 這條是佛州獨有的，全美最嚴！很多人因此吃悶虧

### PIP 實際能用多少錢？（真實扣一扣）
原始 $10,000 會這樣扣：
- 醫療費先付 80%  
  → 例如看醫生花了 $12,000 → PIP 只付 $8,000（80%），剩下的 $4,000 自己想辦法
- 如果有健保（Health insurance），健保會付剩下的 20%，你幾乎不用自付
- 沒有健保 → 剩下的 20% 就自費，或找律師去告對方 BI

實際可用金額排行（真實經驗）：
- 有健保（Obama Care、公司保險）→ 幾乎可以用滿 $12,000～$15,000 醫療費
- 完全沒健保 → 最多只能用 $10,000（80% = $8,000 + 20% 自付很痛）

### 什麼情況可以「突破 $10,000 PIP」去告對方？
只有以下 4 種情況才能告對方拿 Bodily Injury（大錢）：
1. 醫療費超過 $10,000（很少見）
2. 永久性傷害（Permanent injury）→ 例如骨折、椎間盤突出、永久疤痕
3. 明顯且永久的疤痕（Significant & permanent scarring）
4. 失去重要身體機能（Loss of a bodily function）

只要醫生在報告上寫「Permanent injury」這四個字，你就可以找律師告了！

### 2025 年最新 PIP 小技巧（老司機才知道）
- 去整脊（Chiropractor）最快、最簡單，14 天內隨便約都排得到
- 很多整脊診所專門接車禍病人，免費接送、幫你寫報告、直接跟保險公司收錢
- PIP 用完後，律師會叫你轉去用 Medicare / Medicaid / LOP（Letter of Protection），繼續免費看醫生

### 一句話總結佛州 PIP
「14 天內一定要看醫生，不然 $10,000 直接燒掉！  
有健保＝醫療幾乎全包，沒健保＝最多只賠 $8,000」

### 官方要求拍這9張照片（一定要照這個順序跟角度，否則會被退件！）
用 Progressive APP 裡的「Photo Estimate」功能會一步步引導你，但如果你還沒收到連結，手動拍也一樣認。記得開戶外光線、不要反光、整台車要乾淨。

1. **VIN 碼**（車身號碼）

3. **四個角 45 度角**（總共4張）

   - 右前 45 度  
   - 左後 45 度

     - 第一張：距離1公尺遠（看得出是左前）  
     - 第二張：距離30公分特寫裂痕、掉漆  
     - 第三張：距離10公分以內，連刮痕深淺都看得見

## 在佛羅里達州車禍後租車（Rental car）超常見，尤其是車子在修或全損時！根據 Progressive 的 2025 年規定（他們的 Rental Reimbursement Coverage 是 optional 加保），下面告訴你完整處理流程 + 最快拿錢的方法（99% 案子都這樣走，別讓租車費白花）。

### 1. 先確認你有沒有 Rental Reimbursement 保險（Progressive 專屬）
- 打開 Progressive APP → 點「Policy Details」→ 找「Rental Reimbursement」或「Transportation Expenses」  
  → 如果有：每天上限 $40～$70（佛州平均 $50），最多 30～45 天，總上限 $1,500（視你的保單）  
  → 沒有：別慌！用對方保險的 Liability 來賠（佛州對方全責的話，他們會付）  
- 沒加保？下次記得加，月費才 $10 不到，超值！

### 2. 租車前要做的（避免自己先墊太多錢）
- 事故後馬上打 Progressive 1-800-776-4737 → 給 Claim Number → 說：「I need rental car reimbursement, what's my daily limit?」  
  → 他們會告訴你上限，然後幫你找 Enterprise/Hertz 等合作租車公司（免費接送 + 打折）  
- 去租車時：  
  - 選 Economy 或 Compact 車（別選豪華車，保險只賠基本款）  
  - 租車合約上寫「For insurance claim」 + 你的 Claim Number  
  - 別買租車公司的額外保險（Collision Waiver），用你的 Progressive 就夠  
- 佛州小提醒：租車最多付 30 天（從事故日算起），超過要自己談或找律師。

### 3. 怎麼理賠租車費（兩種情況，最快拿錢順序）
#### A. 你自己是 Progressive 客戶（有 Rental Reimbursement）
1. 租完車後，每週（或每天）拍租車收據 → 用 APP 上傳給你的 Adjuster  
2. 他們會直接付租車公司（不用你墊錢），或 3～5 天內打錢給你  
3. 時間：從上傳照片那天起，48 小時內錢就到（Progressive 超快）  

#### B. 對方全責（用對方保險或 Liability 賠）
1. 先用你的信用卡或現金租車（墊錢），保留所有收據  
2. 打對方保險（如果是 Progressive，打 1-800-776-4737 按 2）→ 說：「Third party rental reimbursement for Claim [你的 Claim Number]」  
3. 上傳收據 + 警察報告 → 他們會調查責任（通常 3～7 天），確認後 7～10 天打錢  
4. 如果對方沒保險：用你的 UM/PD（Uninsured Motorist）來賠，流程一樣  

| 情況 | 誰付錢？ | 最快時間 | 每天上限（佛州平均） |

A. 讓對方保險「直接跟租車公司開帳」（Direct Billing）→ 你完全不用墊錢！  
   → 打上面電話 → 說：「I’m at Enterprise/Hertz right now, can you call them and set up direct billing?」  
   → 給租車公司櫃台電話，他們會三方通話，10 分鐘搞定

B. 你先用信用卡墊錢 → 之後拿收據跟他們報銷（95%的人都這樣）

   1. 租車收據（要寫明每天金額 + 總額）
   2. 租車合約（第一頁＋最後一頁）
   3. 警察報告（證明對方全責）
   4. 你的銀行帳號（IBAN + Routing Number）  
   → 傳完立刻打電話確認收到，說：「Florida law requires payment within 30 days, I need this within 7 days.」
