# RAV4 小電池沒電 發動


1. 準備啟動用電霸
1. 用鑰匙開門，打開前車蓋
2. 前車蓋裡，打開右手黑色蓋子的保險絲盒
3. 保險絲盒裡的左上角紅色蓋子，即為正極，先接上正極
4. 車子架上的任意金屬點，即為負極，如前蓋內的中間的銀色，再接上負極
5. 打開電霸
6. 到駕駛室，發動車子
7. 發動後，等五分鐘電池較穩定後，再行駛。
8. 發動後，保持開啟30分鐘。讓電池能充上30%的電。
9. 多走些長程，可以讓小電池能充上電。
