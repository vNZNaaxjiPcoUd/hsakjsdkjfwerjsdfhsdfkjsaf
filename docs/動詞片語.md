動詞片語
=======

以下是英文學習者最常用、也最實用的 **動詞片語 (Phrasal Verbs)**，按照意思分類整理，並附上中文解釋與例句。這些幾乎涵蓋了日常對話、考試（TOEIC、IELTS、TOEFL）、職場英文的 90% 使用場景。

### 1. 起身／日常生活類
- get up 起床  
- wake up 醒來  
- go to bed 上床睡覺  
- fall asleep 睡著  
- get dressed 穿衣服  
- put on 穿上（衣服）  
- take off 脫掉（衣服／起飛）  
- turn on 打開（燈、電器）  
- turn off 關掉  
- pick up 撿起；接人；學會  
- hang up 掛斷電話；掛起來  
- throw away 扔掉  
- clean up 打掃乾淨

### 2. 外出／移動類
- go out 出去（玩樂）  
- come back 回來  
- get in 上車／進入  
- get off 下車  
- get on 上車  
- set off/out 出發  
- take off （飛機）起飛  
- run out of 用完、耗盡  
- drop by/off 順路拜訪／送人  
- check in 進來  
- go away 走開、離開

### 3. 溝通類
- call back 回電  
- hang up 掛電話  
- find out 查出、發現  
- look up 查（字典、網路）  
- speak up 說大聲點  
- fill in/out 填寫（表格）  
- point out 指出  
- talk over 詳細討論  
- get along with 與…相處融洽  
- catch up with 追上；敘舊

### 4. 工作／學習類
- turn in 繳交（作業）  
- hand in/out 交出／發放  
- carry on 繼續  
- put off 延後  
- look forward to 期待  
- give up 放棄  
- take up 開始從事（興趣）  
- work out 解決；運動；計算結果  
- figure out 想出、弄懂  
- go over 複習、檢查  
- catch up on 補完（落後的工作）

### 5. 關係／情感類
- break up 分手  
- make up 和好；化妝  
- get together 聚會  
- cheer up 讓…開心  
- calm down 冷靜下來  
- let down 讓…失望  
- turn down 拒絕  
- ask out 約出去  
- fall for 愛上  
- get over 克服；從（失戀、生病）恢復

### 6. 其他高頻片語
- run into 偶遇  
- come across 偶然發現  
- look after 照顧  
- take care of 照顧  
- pay back 還錢  
- pay off 還清（債務）；成功  
- show up 出現  
- end up 最後變成  
- grow up 長大  
- hold on 等一下（電話）  
- hurry up 快點  
- slow down 慢下來  
- come up with 想出（點子）  
- deal with 處理  
- rely on 依賴
