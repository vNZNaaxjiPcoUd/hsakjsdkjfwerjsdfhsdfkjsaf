# 佛跳牆

佛跳牆的食材眾多，做法也較為繁複，但掌握了關鍵步驟，在家也能做出美味的佛跳牆。

### 食材準備：

**主要食材：**

*   **雞湯底：**
    *   老母雞：1隻 (約1.5-2公斤)
    *   豬大骨：500克
    *   薑片：數片
    *   蔥段：數段
    *   米酒：少許
*   **海鮮類：**
    *   乾鮑魚：2-4頭 (依喜好與預算)
    *   海參：2-4條 (依喜好與預算)
    *   乾干貝：10-15顆
    *   蝦米：適量
    *   烏參：1條 (可省略)
    *   魚翅：一小片 (可省略，或用雞翅代替)
*   **肉類：**
    *   豬腳筋：100克
    *   豬肚：1個 (處理乾淨)
    *   雞腿肉：1-2隻 (去骨切塊)
    *   五花肉：100克 (切塊)
*   **其他：**
    *   香菇：乾香菇數朵 (泡發)
    *   栗子：10-15顆 (去殼)
    *   鳥蛋：10-15顆 (煮熟剝殼)
    *   筍片：適量 (新鮮或罐頭)
    *   薑：少許 (切片或末)
    *   蒜：少許 (切片或末)
    *   蔥：少許 (切段)
    *   米酒：適量
    *   醬油：適量
    *   蠔油：適量
    *   糖：少許
    *   白胡椒粉：少許
    *   高湯：適量 (若雞湯底不夠)

**前置處理：**

1.  **乾貨泡發：** 鮑魚、海參、干貝、香菇、蝦米需提前泡發。鮑魚和海參可泡軟後，用薑、蔥、米酒汆燙，去除腥味。干貝泡發後保留泡發的水。
2.  **肉類處理：** 雞腿肉、五花肉切塊，用醬油、米酒、白胡椒粉醃製。豬腳筋、豬肚處理乾淨，可先汆燙。
3.  **雞湯底熬製：** 老母雞和豬大骨汆燙後，與薑、蔥、米酒一起燉煮數小時，熬出濃郁的雞湯。過濾掉雜質，備用。

### 製作步驟：

1.  **食材預處理與燉煮：**
    *   將泡發好的鮑魚、海參、干貝、香菇、栗子、鳥蛋、豬腳筋、豬肚、雞腿肉、五花肉等，分別用少許油炒香，加入醬油、蠔油、米酒、糖、薑、蒜調味，略為燉煮入味。
    *   **注意：** 不同的食材烹調時間不同，可分批處理或事先處理好。例如，較難熟的豬肚、豬腳筋可以先燉煮一段時間。

2.  **組合與燉煮：**
    *   準備一個適合燉煮的甕或砂鍋。
    *   將所有預處理好的食材，依序放入甕中。
    *   倒入熬好的雞湯底，水量需蓋過食材。若雞湯不夠，可加入高湯或清水。
    *   加入泡發干貝的水，增加鮮味。
    *   蓋上蓋子，用中小火慢燉。燉煮時間至少 **2-3小時**，甚至更久，讓食材的味道充分融合，湯汁濃稠。
    *   燉煮過程中，可偶爾檢查水量，避免燒乾。

3.  **起鍋與享用：**
    *   燉煮完成後，即可將佛跳牆盛盤享用。
    *   可依個人喜好，在起鍋前加入少許蔥段或香菜點綴。

### 溫馨提示：

*   **食材彈性：** 佛跳牆的食材非常彈性，可依個人喜好和預算增減。例如，可加入排骨、鴨肉、鹌鹑蛋、竹笙等。
*   **湯頭關鍵：** 雞湯底是佛跳牆的靈魂，務必用心熬製。
*   **燉煮時間：** 燉煮時間越長，味道越濃郁，食材越軟爛。
*   **甕的選擇：** 使用陶甕或砂鍋燉煮，保溫性好，能讓食材均勻受熱。
*   **隔夜更美味：** 佛跳牆放隔夜後，味道會更融合，風味更佳。

佛跳牆是一道功夫菜，但只要耐心準備，就能在家品嚐到這道極致的美味。
