# 退回寄錯的信


在美國（包括佛羅里達州），處理不屬於你的郵件主要遵循美國郵政署（USPS）的聯邦規定。即使地址正確但收件人姓名不對（例如前住戶），你也有法律義務妥善處理。

以下是針對 **First Class (一類信件)** 的具體操作步驟：

### 1. 千萬不要做的事（法律警告）
*   **不要拆開信件：** 故意拆開他人的信件是聯邦罪行（Obstruction of Correspondence），最高可判處罰款或監禁。
*   **不要直接扔掉：** 隨意丟棄他人郵件也是違法的，特別是 First Class 郵件受聯邦法律保護。

### 2. 具體操作步驟

#### 情況 A：地址正確，但收件人不是你（如前住戶）
這是最常見的情況。First Class 郵件是可以免費退回或轉寄的。
1.  **在信封正面清晰標註：** 用原子筆或馬克筆寫上 **"Not at this address"** 或 **"Return to Sender"**（退回發件人）。
2.  **不要塗改原地址：** 不要把原本的名字或地址塗黑，否則郵政機器可能無法識別退回路徑。
3.  **放回郵箱：** 將信件放回你的郵箱，並把郵箱旁邊的小紅旗豎起來（如果有），或者直接投入路邊的 USPS 藍色郵筒。郵差在下次送信時會將其取走。

#### 情況 B：地址寫錯了（投遞錯誤）
如果信上的地址根本不是你家，只是郵差投錯了：
1.  **簡單處理：** 將信件放回郵箱，豎起紅旗即可。
2.  **標註（可選）：** 也可以附上一張便條寫 **"Misdelivered to wrong address"**。
3.  **手動轉送（僅限鄰居）：** 如果收件人就在隔壁，且你方便的話，可以直接投進鄰居的郵箱。

### 3. 如果你不小心拆開了信？
如果因為沒看清姓名誤拆了：
1.  用膠帶封好。
2.  在信封上寫 **"Opened by mistake"**（誤拆）。
3.  按照上述步驟標註 "Not at this address" 並退回。通常這種無心之過不會惹上法律麻煩。

### 4. 如何永久停止收到前住戶的信？
如果這類信件源源不斷，你可以：
*   **貼個小標籤：** 在郵箱內部貼一張標籤，寫上：**"Only [你的姓氏] Family"** 或 **"[前住戶姓名] no longer lives here"**。這能提醒郵差在投遞前過濾掉錯誤名字。
*   **去郵局說明：** 如果情況嚴重，可以親自去當地的 Post Office，告訴櫃台職員該地址的前住戶已經搬走，請他們更新資料（填寫內部表格 3575Z）。

### 為什麼 First Class 很重要？
你收到的是 **First Class**，這意味著 USPS **必須**負責將其退還給寄件人或轉寄。如果是那種寫著 "Standard"、"Marketing" 或 "Presorted Standard" 的廣告垃圾郵件（Junk Mail），郵局通常不負責退回，你可以直接回收處理。但對於 First Class，請務必退回。
