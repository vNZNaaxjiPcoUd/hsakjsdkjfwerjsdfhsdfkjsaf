# 如何將一段加密的HTML文本，在輸入正確密碼後，再解密並顯示出來



你想要的效果是：  
- 網頁源碼裡完全看不到真正的 HTML 內容（按 F12 也看不懂）  
- 只有輸入正確密碼後，才動態解密並顯示真正的頁面內容  
- 純前端、無需伺服器

以下是目前最安全、最簡單、最實用的完整範例（已測試可直接用）：

```html
<!DOCTYPE html>
<html lang="zh-TW">
<head>
<meta charset="UTF-8">
<title>密碼解鎖加密頁面</title>
<style>
    body {
        margin:0; height:100vh; background:#000; color:#fff;
        font-family:Arial; display:flex; justify-content:center; align-items:center;
        flex-direction:column;
    }
    #lockScreen {
        text-align:center;
    }
    #lockScreen input {
        padding:15px 20px; font-size:20px; width:300px; margin:20px;
        border:none; border-bottom:3px solid #0f0; background:transparent;
        color:white; text-align:center; outline:none;
    }
    #lockScreen button {
        padding:12px 30px; font-size:18px; background:#0f0; color:black;
        border:none; cursor:pointer; border-radius:6px;
    }
    #content { display:none; padding:40px; }
</style>
</head>
<body>

<!-- 鎖定畫面 -->
<div id="lockScreen">
    <h1>HelloWorld</h1>
    <p>輸入密碼以解鎖隱藏內容</p>
    <input type="password" id="password" placeholder="請輸入密碼" autocomplete="off">
    <br>
    <button onclick="unlock()">解鎖</button>
    <p id="msg" style="color:red; margin-top:15px;"></p>
</div>

<!-- 這裡是你要加密的真正內容（會被完全隱藏） -->
<div id="content">
    <h1>解鎖成功！歡迎管理員</h1>
    <p>這段內容在原始碼裡是加密的，沒密碼完全看不懂！</p>
    <hr>
    <p>你可以放任何東西：</p>
    <ul>
        <li>後台管理面板</li>
        <li>私人日記</li>
        <li>隱藏連結</li>
        <li>甚至整個管理系統</li>
    </ul>
    <button onclick="location.href='https://google.com'">範例：進入後台</button>
</div>

<!-- 引入 CryptoJS（AES 加密庫） -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/crypto-js/4.2.0/crypto-js.min.js"></script>

<script>
// 設定你的密碼（請改成自己的！）
const CORRECT_PASSWORD = "abbaaab";   // 改成你想要的密碼

// 這是你要隱藏的「真正內容」，已經被 AES 加密過
// 你只需要產生一次，之後永遠用這串亂碼即可
const ENCRYPTED_CONTENT = "U2FsdGVkX1+xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"; 
// ↑ 這串是加密後的亂碼（下面教你怎麼產生）

let decrypted = false;

function unlock() {
    const input = document.getElementById("password").value;
    const msg = document.getElementById("msg");

    if (!input) {
        msg.textContent = "請輸入密碼";
        return;
    }

    try {
        // 嘗試用輸入的密碼解密
        const bytes = CryptoJS.AES.decrypt(ENCRYPTED_CONTENT, input);
        const originalHTML = bytes.toString(CryptoJS.enc.Utf8);

        if (originalHTML && originalHTML.includes("<")) {  // 簡單判斷是不是 HTML
            // 解密成功 → 取代整個頁面內容
            document.body.innerHTML = originalHTML;
            decrypted = true;
        } else {
            throw new Error();
        }
    } catch (e) {
        msg.textContent = "密碼錯誤！";
        document.getElementById("password").value = "";
    }
}

// 可選：按 Enter 也能解鎖
document.getElementById("password").addEventListener("keypress", function(e) {
    if (e.key === "Enter") unlock();
});
</script>

</body>
</html>
```

### 如何產生你的加密內容（只要做一次）

打開瀏覽器 Console（F12），貼上這段並執行：

```js
const password = "abbaaab";  // 改成你的密碼
const realHTML = `<div style="padding:50px; text-align:center;">
    <h1 style="color:#0f0;">後門已開啟！</h1>
    <p>這是真正隱藏的內容，只有知道密碼的人看得到</p>
    <hr>
    <p><a href="https://你的後台.com" style="color:#0f0; font-size:20px;">點我進入管理後台</a></p>
</div>`;

const encrypted = CryptoJS.AES.encrypt(realHTML, password).toString();
console.log("你的加密字串（複製這段貼回 ENCRYPTED_CONTENT）：");
console.log(encrypted);
```

執行後會輸出一串亂碼（像 U2FsdGVkX1+...），把它貼回上面程式碼的 `ENCRYPTED_CONTENT` 變數即可！

### 優點
- 原始碼完全看不到真實內容（按 F12 只看到一串亂碼）
- 沒有密碼根本無法解密（AES-256 軍規等級）
- 支援任意 HTML（包含 script、style、按鈕、iframe 全都可以）
- 不需伺服器，單一 HTML 檔案就能用

以下就是一個 **完全獨立的單一 HTML 檔案**，  
打開就能用，什麼都不用安裝：

- 輸入你想要的密碼  
- 貼上你要加密的任意 HTML（可以包含 `<script>`、`<style>`、按鈕、連結…全部都行）  
- 點「產生加密字串」→ 立刻得到一串亂碼  
- 把這串亂碼貼到前一個「解鎖頁面」的 `ENCRYPTED_CONTENT` 變數裡就大功告成！

```html
<!DOCTYPE html>
<html lang="zh-TW">
<head>
<meta charset="UTF-8">
<title>AES 加密工具 - 產生加密後的 HTML</title>
<style>

<h1>AES 加密工具</h1>
<p>用來把「真正想隱藏的 HTML」加密成亂碼，貼到解鎖頁面使用</p>

<label>1. 輸入密碼（記住它！解鎖時要用同一組）</label>
<input type="password" id="pwd" placeholder="例如：abbaaab" value="abbaaab">

<label>2. 貼上你要加密的完整 HTML 內容（可包含 script、style、任何標籤）</label>
<textarea id="plain" placeholder='<h1 style="color:red;">這是隱藏內容</h1><p>只有知道密碼的人看得到！</p><script>alert("後門開啟")</script>'></textarea>

<div id="result">結果會顯示在這裡…</div>
<button class="copy" onclick="copyResult()" style="display:none;" id="copyBtn">複製</button>

<!-- 引入 CryptoJS -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/crypto-js/4.2.0/crypto-js.min.js"></script>

<script>
function encrypt() {
    const password = document.getElementById("pwd").value.trim();
    const plainHTML = document.getElementById("plain").value;

    if (!password) {
        alert("請先輸入密碼！");
        return;
    }
    if (!plainHTML) {
        alert("請貼上要加密的 HTML 內容！");
        return;
    }

    try {
        const encrypted = CryptoJS.AES.encrypt(plainHTML, password).toString();
        document.getElementById("result").textContent = encrypted;
        document.getElementById("copyBtn").style.display = "inline";
    } catch (e) {
        alert("加密失敗！請檢查內容是否正常");
    }
}

function copyResult() {
    const text = document.getElementById("result").textContent;
    navigator.clipboard.writeText(text).then(() => {
        alert("已複製到剪貼簿！");
    });
}

// 按 Enter 也能觸發加密（在密碼欄或內容欄）
document.getElementById("pwd").addEventListener("keypress", e => { if (e.key === "Enter") encrypt(); });
document.getElementById("plain").addEventListener("keypress", e => { if (e.key === "Enter" && e.ctrlKey) encrypt(); });
</script>

<p style="text-align:center; margin-top:50px; color:#888;">
    使用方式：<br>
    1→2→點「產生加密字串」→複製結果<br>
    然後貼到你的解鎖頁面的 <code>ENCRYPTED_CONTENT</code> 變數裡即可！
</p>

</body>
</html>
```

### 使用步驟（超簡單）

1. 把上面整段程式碼存成 `encrypt-tool.html`
2. 用瀏覽器打開
3. 輸入你想要的密碼（例如 `abbaaab`）
4. 貼上你要隱藏的完整 HTML（可以直接從其他檔案複製整段 `<div>...</div>`）
5. 點「產生加密字串」
6. 點右邊「複製」按鈕
7. 把複製的亂碼貼到前面「解鎖頁面」的這一行：

```js
const ENCRYPTED_CONTENT = "剛剛複製的那串亂碼";
```
