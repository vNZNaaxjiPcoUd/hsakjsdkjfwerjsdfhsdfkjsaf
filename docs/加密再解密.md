# 如何將一段加密的HTML文本，在輸入正確密碼後，再解密並顯示出來



你想要的效果是：  
- 網頁源碼裡完全看不到真正的 HTML 內容（按 F12 也看不懂）  
- 只有輸入正確密碼後，才動態解密並顯示真正的頁面內容  
- 純前端、無需伺服器

以下是目前最安全、最簡單、最實用的完整範例（已測試可直接用）：

```html
<!DOCTYPE html>
<html lang="zh-TW">
<head>
<meta charset="UTF-8">
<title>密碼解鎖加密頁面</title>

<!-- 引入 CryptoJS（AES 加密庫） -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/crypto-js/4.2.0/crypto-js.min.js"></script>

<script>
// 設定你的密碼（請改成自己的！）
const CORRECT_PASSWORD = "abbaaab";   // 改成你想要的密碼

// 這是你要隱藏的「真正內容」，已經被 AES 加密過
// 你只需要產生一次，之後永遠用這串亂碼即可
const ENCRYPTED_CONTENT = "U2FsdGVkX1+xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"; 
// ↑ 這串是加密後的亂碼（下面教你怎麼產生）

let decrypted = false;

function unlock() {
    const input = document.getElementById("password").value;
    const msg = document.getElementById("msg");

    if (!input) {
        msg.textContent = "請輸入密碼";
        return;
    }

    try {
        // 嘗試用輸入的密碼解密
        const bytes = CryptoJS.AES.decrypt(ENCRYPTED_CONTENT, input);
        const originalHTML = bytes.toString(CryptoJS.enc.Utf8);

        if (originalHTML && originalHTML.includes("<")) {  // 簡單判斷是不是 HTML
            // 解密成功 → 取代整個頁面內容
            document.body.innerHTML = originalHTML;
            decrypted = true;
        } else {
            throw new Error();
        }
    } catch (e) {
        msg.textContent = "密碼錯誤！";
        document.getElementById("password").value = "";
    }
}

// 可選：按 Enter 也能解鎖
document.getElementById("password").addEventListener("keypress", function(e) {
    if (e.key === "Enter") unlock();
});
</script>

</body>
</html>
```

### 如何產生你的加密內容（只要做一次）

打開瀏覽器 Console（F12），貼上這段並執行：

```js
const password = "abbaaab";  // 改成你的密碼
const realHTML = `<div style="padding:50px; text-align:center;">
    <h1 style="color:#0f0;">後門已開啟！</h1>
    <p>這是真正隱藏的內容，只有知道密碼的人看得到</p>
    <hr>
    <p><a href="https://你的後台.com" style="color:#0f0; font-size:20px;">點我進入管理後台</a></p>
</div>`;

const encrypted = CryptoJS.AES.encrypt(realHTML, password).toString();
console.log("你的加密字串（複製這段貼回 ENCRYPTED_CONTENT）：");
console.log(encrypted);
```

執行後會輸出一串亂碼（像 U2FsdGVkX1+...），把它貼回上面程式碼的 `ENCRYPTED_CONTENT` 變數即可！

- 支援任意 HTML（包含 script、style、按鈕、iframe 全都可以）
